# Результаты рендера

В Git оставляем только текущие пользовательские результаты:

- `pilot-letter-p.mp4` — актуальная пробная серия, 40 секунд, 1080p;
- `pilot-letter-p-poster.jpg` — постер этой версии;
- этот файл.

Все остальные превью, контакт-листы, временные MP4, WAV и QA-отчёты —
воспроизводимые производные; они исключены из Git через `.gitignore`.
Старые 37 диагностических файлов удалены из текущего дерева, не из истории.

Исходные изображения, библиотеки поз, лица, риги и сжатые записи речи
**не удалялись**: они живут в `characters/`, `2p5d/`, `assets/` и других
исходных каталогах.

Пересборка текущего ролика из корня репозитория:

```bash
.venv/bin/python studio/tools/render_pilot.py
```

Контакт-лист и контрольные кадры для локального просмотра:

```bash
.venv/bin/python studio/tools/render_pilot.py --stills
# → studio/out/letter-p/contact.jpg
```

Подробности: `docs/31-PILOT-LETTER-P.md` и
`docs/32-CLEANUP-AND-ACTING.md`. Старые инструкции в исторических документах
могут ссылаться на результаты в этом каталоге: их надо пересобрать
соответствующим инструментом, они больше не поставляются как исходники.

# Забракованная партия 0 (архив решения)

Здесь лежали кадры, в которых модель рисовала героев **с нуля** по текстовому
описанию. Лица и пропорции не совпадали с мастерами — приёмку это не прошло.

Сами файлы не сохранены: брак не имеет смысла хранить, а каталог `out/` первого
прогона не пережил сброса окружения. Осталась причина — она и важна.

Брак системный, а не «неудачный промпт»: текстовое описание задаёт класс объекта
(«бородатый папа в сером худи»), а не конкретное лицо, поэтому каждая генерация
даёт нового героя. Референце лица не спасают — модель усредняет черты.

Отсюда правило №0 (`docs/34-IDENTITY-LOCK.md`): **герой попадает в промо-кадр
только вырезкой из мастер-файла**, генерация отвечает за фон, свет и реквизит.

# P06 · Первые пять секунд

- **Неделя:** -1 (09.11)
- **Канал:** YouTube Shorts + Telegram
- **Формат:** Обложка шортса / сторис (9:16) · 1080×1920
- **Герои:** Папа
- **Цель поста:** тизер: крючок без спойлера
- **Статус:** brief

## Как собирается кадр

Герои **не генерируются**: кадр собирается из мастер-файлов, поэтому лицо и
пропорции совпадают с эталоном пиксель в пиксель.

| кадр | что | файл |
|------|-----|------|
| `dad:carry` | Папа, несёт коробку | `studio/2p5d/dad/poses/carry.png` |

```bash
.venv/bin/python studio/engine/promo_scene.py scene --format shorts-cover --cast dad:carry --bg studio/promo/plates/room-living-empty.png --dad 0.80 --baseline 0.90 --out studio/promo/renders/P06-art.png
```

Компоновка: папа с коробкой; тизер без спойлера

Доказательство для приёмки: `.venv/bin/python studio/engine/promo_scene.py proof dad:carry`

## Правила кадра

- Безопасная зона: 72 px; «мёртвые» области: верх — заголовок канала, низ — кнопки и подпись, края — свайп
- Заголовок: до 5 слов, до 3 строк.
- герой целиком между 18 % и 80 % высоты; заголовок в средней трети, крупно
- Текст — только нашим слоем, модель кириллицу не рисует.

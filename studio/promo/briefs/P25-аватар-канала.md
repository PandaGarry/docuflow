## Как собирается кадр

Герои **не генерируются**: кадр собирается из мастер-файлов, поэтому лицо и
пропорции совпадают с эталоном пиксель в пиксель.

| кадр | что | файл |
|------|-----|------|
| `son:point` | Сын, палец в камеру | `studio/characters/son/pose/point.png` |

```bash
.venv/bin/python studio/engine/promo_scene.py plate --format avatar --cast son:point --dad 0.80 --baseline 0.90 --out studio/promo/renders/P25-art.png
```

Компоновка: аватар: кроп лица из мастер-портрета characters/son/master/face.png

Доказательство для приёмки: `.venv/bin/python studio/engine/promo_scene.py proof son:point`

## Фон

Плоская студия (бумага + шалфейная панель) — генерировать не нужно.

## Типографика

```bash
.venv/bin/python studio/engine/promo.py compose studio/promo/renders/P25-art.png \
    --format avatar --kicker "…" --title "Аватар канала" \
    --plate --out studio/promo/renders/P25-avatar.png
```

## Текст

**Аватар канала**

Одно лицо крупно, без надписей: в списке чатов иконка 40 px, текст в ней не читается.

**Призыв:** Проверить в мобильном списке чатов.



## Правила кадра

- Безопасная зона: 90 px; «мёртвые» области: обрезается в круг r=400 — всё важное в круге r=320
- Заголовок: до 2 слов, до 1 строк.
- одно лицо крупно, без текста (или 1–2 буквы)
- Текст — только нашим слоем, модель кириллицу не рисует.

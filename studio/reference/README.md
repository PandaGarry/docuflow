# reference/ — личные референсы (НЕ в репозитории)

Здесь локально лежат фотографии реальной семьи: по ним проектируются
карикатурные герои (пропорции, черты лица, причёски).

**Правило:** файлы из этой папки не попадают в git и не публикуются.
В репозитории остаётся только этот README.

```gitignore
studio/reference/*
!studio/reference/README.md
```

Почему так:

- это личные данные третьих лиц (в том числе ребёнка) — им не место в публичном
  репозитории, даже в закрытой ветке;
- герои сериала — карикатуры, а не копии: для производства нужны мастер-ассеты,
  а не исходные фотографии;
- если нужен новый герой, фото кладётся локально, используется один раз для
  промпта и остаётся на машине.

Если фотографии когда-то попали в историю git — историю надо переписать
(`git filter-repo`/`filter-branch`) и сделать репозиторий приватным, потому что
обычное удаление файла оставляет его в старых коммитах.

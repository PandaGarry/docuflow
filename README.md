# docuflow

Коллекция готовых видеороликов и их «исходников»: каждый ролик — это
воспроизводимый пайплайн (кадры → графика → звук → MP4), а не бинарник без
происхождения. Пересобрать можно одной командой.

### Мультик «Уборка»

Весёлая карикатурная история: ребёнок выпросил гостей, после гостей — бардак,
мама просит убрать игрушки… и получает ответ, ради которого всё снято.

Сделано как настоящий мультфильм, а не слайд-шоу: персонажи в 4–5 позах,
cut-out анимация (дыхание, сквош-стретч, подскоки «пружинкой»), речевые пузыри,
комикс-надписи, конфетти, спидлайны, тряска камеры, монтажные вставки в сцене
вечеринки. Звук: укулеле-тема, комикс-эффекты (скретч, хлопок двери, сверчки,
boing) и две озвучки с дакингом музыки.

```bash
cd campaigns/toys
./build.sh                      # спрайты -> звук -> видео -> субтитры
./build.sh --preview 8.5 24     # статичные кадры для проверки вёрстки
```

### iPad Air — концепт-промо

Современный рекламный ролик: продуктовые кадры, кинетические титры, световые
переходы, музыка, саунд-дизайн и русская озвучка.

```bash
cd campaigns/ipad-air
./build.sh
./build.sh --preview 9 18.5 36
```

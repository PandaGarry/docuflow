# docuflow

Коллекция готовых видеороликов и их «исходников»: каждый ролик — это
воспроизводимый пайплайн (кадры → графика → звук → MP4), а не бинарник без
происхождения. Пересобрать можно одной командой.

## Ролики

| Ролик | Формат | Файл | Исходники |
|-------|--------|------|-----------|
| iPad Air — концепт-промо | 9:16, 1080×1920, 42 с, RU-озвучка | [`campaigns/ipad-air/out/ipad-air-promo.mp4`](campaigns/ipad-air/out/ipad-air-promo.mp4) | [`campaigns/ipad-air`](campaigns/ipad-air) |

### iPad Air — концепт-промо

Современный рекламный ролик: продуктовые кадры, кинетические титры, световые
переходы, музыка, саунд-дизайн и русская озвучка. Собирается скриптами на
Python (PIL/numpy) + ffmpeg, без монтажных приложений.

```bash
cd campaigns/ipad-air
./build.sh                      # полная пересборка (звук + видео)
./build.sh --preview 9 18.5 36  # статичные кадры для проверки вёрстки
```

Подробности: сценарий, тайминг, устройство пайплайна и лицензии —
в [`campaigns/ipad-air/README.md`](campaigns/ipad-air/README.md).

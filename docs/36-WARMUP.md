# 36 · Прогрев сообщества до премьеры

_Что постить, пока сериал ещё делается. Без обещаний серий, которые не готовы._

## Логика

Сериал в производстве. Поэтому сообщество заполняем не «сериями», а тремя
вещами, которые у нас уже есть и не устареют:

1. **Герои.** Люди подписываются на персонажей, а не на дату. Карточка «папа,
   который всё продумал» работает и без единой серии.
2. **Тон.** Сухой юмор «мы переехали и всё сломалось» — это то, за чем приходят.
   Каждый плакат — шутка, а не анонс.
3. **Загадка.** Силуэты, «кто переезжает?», крупы лиц: интерес к тому, что за
   семья, дешевле, чем интерес к дате.

Чего не делаем: не обещаем дат, которых нет; не пишем «скоро серия», пока серии
нет; не выкладываем кадры, где герой отличается от мастера (правило №0,
`docs/34-IDENTITY-LOCK.md`).

## Пачка «прогрев» (9 плакатов)

Все собираются детерминированно из мастеров:

```bash
.venv/bin/python studio/engine/promo_poster.py all     # 9 кадров
.venv/bin/python studio/engine/promo_poster.py sheet   # контакт-лист
.venv/bin/python studio/engine/promo_poster.py list    # какие режимы есть
```

| # | файл | режим | что говорит |
|---|------|-------|-------------|
| 1 | `warmup-01-announce.png` | `announce` | имя сериала и трио; «12 серий по 40 секунд» |
| 2 | `warmup-02-quote.png` | `quote` | «Я всё продумал.» — папа |
| 3 | `warmup-03-silhouette.png` | `silhouette` | «кто переезжает?» — тизер |
| 4 | `warmup-04-portrait.png` | `portrait` | карточка папы, круг с лицом |
| 5 | `warmup-05-faces.png` | `faces` | «одна семья · три характера» |
| 6 | `warmup-06-meme.png` | `meme` | «Тут всё влезет» — папа |
| 7 | `warmup-07-quote-mom.png` | `quote` | «Ты серьёзно?» — мама |
| 8 | `warmup-08-portrait-son.png` | `portrait` | карточка сына |
| 9 | `warmup-09-meme-facepalm.png` | `meme` | «Сейчас найду» — папа |

## Порядок публикации

Три недели, 2 поста в неделю. Порядок важен: сначала «что это», потом «кто они»,
потом шутки.

| Неделя | Пост | Зачем такой порядок |
|--------|------|---------------------|
| −3 | 1 · announce | объявление: появляется то, на что можно подписаться |
| −3 | 4 · portrait папа | первый герой, лицо крупно: узнаваемость |
| −2 | 5 · faces | вся семья сразу, знакомство закрыто |
| −2 | 6 · meme | первая шутка: проверяем, смешно ли аудитории |
| −1 | 2 · quote папа | характер папы, а не только лицо |
| −1 | 7 · quote мама | второй голос, семья перестаёт быть «про папу» |
| −1 | 8 · portrait сын | третий герой, полный состав |
| 0 | 9 · meme | шутка перед премьерой, разогрев комментариев |
| 0 | 3 · silhouette | тизер: вопрос, на который ответит серия |

Правила: один пост — одна мысль; без «поддержите нас репостом»; в комментариях
отвечаем голосом героя, не бренда.

## Какие ещё варианты можно собрать из этого же

Движок принимает кадр и реплику, поэтому новые посты — это строчка команды,
а не новая генерация:

```bash
# цитата другого героя
.venv/bin/python studio/engine/promo_poster.py make quote --key mom:stern \
    --line1 "Я так" --line2 "и думала." --who мама --out studio/promo/renders/q.png

# мем с другой позой папы
.venv/bin/python studio/engine/promo_poster.py make meme --key dad:crouch \
    --line "«Ещё пять минут»" --sub "папа · коробка №12" --out studio/promo/renders/m.png

# карточка мамы на 1:1
.venv/bin/python studio/engine/promo_poster.py make portrait --key mom:front \
    --name МАМА --tag "она всё заметит" --out studio/promo/renders/c.png
```

Ограничение — библиотека кадров: у папы 14 (есть `shrug`, `facepalm`, `crouch`,
`sit`, `carry`, `phone`, `surprise`), у мамы и сына по 4. Если под шутку нет
позы — поза дорисовывается в библиотеку и проходит QA, и только потом идёт в
плакат.

## Что дальше

- По мере готовности серий пачка дополняется кадрами из серий (те же правила).
- Когда появятся первые 3–5 серий — переходим на `docs/35-CAMPAIGN-S1.md`:
  календарь на 8 недель, 26 постов, дата премьеры.
- Подписи к постам: `studio/promo/copies/warmup.md`.

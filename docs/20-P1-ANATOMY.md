# P1. Анатомия папы: блокинг, пропорции, лицо

Статус: **чек-поинт P1 (блокинг)**. Персонаж собран процедурно из чисел, а не
нарисован, и это принципиально: любую пропорцию можно изменить одним параметром
и посмотреть результат за секунду, а не перерисовывать.

Смотреть результат: `studio/out/dad-p1-sheet.png` (фронт, 3/4, профиль, крупный
план лица), отдельные файлы `studio/out/dad-p1-*.png`.

## Что сделано

| Файл | Роль |
| --- | --- |
| `studio/engine/render3d.py` | растеризатор: меши, примитивы (`sphere`, `capsule`, `box`, `roundbox`, `loft`, `tube`), камера, свет, `render` |
| `studio/engine/body3d.py` | персонаж из пропорций: `Proportions`, `build_body`, `turnaround`, `face_closeup`, посадка лица по поверхности головы (`head_point`, `head_shell`, `head_spot`) |

### Пропорции (доли роста, не «на глаз»)

`Proportions` хранит **доли роста**; метры появляются только при сборке мешей.
Рост в головах 5.7 (стилизация), ширина плеч 1.50 головы, бёдра 1.22, длина руки
0.42 роста (плечо → запястье), ноги 0.47, живот — отдельный параметр, толщина
конечностей — `bulk`.

Проверка в тестах: при `height` 1.0 → 2.0 макушка масштабируется ровно вдвое,
ничего не вылезает выше макушки и ниже пола, все замкнутые тела ориентированы
наружу.

### Лицо

Лицо сажается **по поверхности головы**, а не «на глаз»:

* `head_point(t, φ)` — точка на черепе (t — относительная высота, φ — угол);
* `head_shell(...)` — накладка (волосы, борода) с бортиком, повторяющая форму
  головы;
* `head_spot(...)` — эллиптическое пятно (глаз, радужка, зрачок, блик, веко,
  бровь, рот).

Глаз = белок + радужка + зрачок + блик + верхнее/нижнее веко, все накладки
разной высоты над кожей. Такой набор потом анимируется (веко опускается,
радужка едет) без перерисовки головы.

## Три ошибки, из-за которых картинка была «битой» (найдены и закрыты)

1. **Конфликт фрагментов внутри батча растеризатора.** Фрагменты писались
   «россыпью» через fancy-indexing, и при двух фрагментах на один пиксель
   побеждал не ближний, а случайно последний. Это и были «тёмные осколки» и
   «белые швы» на всех предыдущих рендерах. Теперь сначала считается максимум
   глубины по пикселю (`np.maximum.at`), затем на пиксель остаётся один
   фрагмент.
2. **Обратный обход треугольников.** У части примитивов нормали смотрели внутрь,
   поэтому отсечение задних граней показывало изнанку — тело выглядело
   «призраком». Добавлен `Mesh.orient_outward()` (по знаку объёма) для всех
   замкнутых тел и тест на это.
3. **Смешение единиц.** Свойства пропорций возвращали и доли роста, и метры
   одновременно: при росте 1.85 голова получалась 26 см вместо 32, а «тело»
   заканчивалось на 1.72. Теперь всё в долях, умножение на рост — в одном месте.

## Что ещё не так (честно)

* Голова — оболочка вращения: нет скул, надбровных дуг, объёма носа и подбородка.
  Читается как «манекен», а не как персонаж стиля B.
* Борода и волосы — накладки постоянной толщины, без прядей и формы.
* Рот — линия-заготовка, губ и зубов нет (это этап P2: 8 вижемов).
* Одежда: худи без капюшона, складок и объёма ткани; рукава — гладкие трубы.
* Кисти — «варежки» без пальцев, стопы — скруглённые бруски.
* Скелета и весов ещё нет: позы пока невозможны (это следующий шаг после P1).

## Как пересобрать

```bash
cd <repo>
.venv/bin/python - <<'PY'
import sys; sys.path.insert(0, "studio/engine")
import body3d as B
p = B.Proportions()
B.turnaround(p, "studio/out/dad-p1", size=(480, 820), ss=3)
B.face_closeup(p, "studio/out/dad-p1-face.png", size=(560, 560), ss=3)
PY
```

Стоимость: 22 140 треугольников, кадр 480×640 ss2 ≈ 0.9 с, 720×1280 ss2 ≈ 2.5 с
(2 ядра, numpy).

## Решение по чек-поинту

P1 считается пройденным, когда силуэт с трёх ракурсов и посадка черт лица
признаны годными. После этого: скелет (18–22 кости) и веса → позы, затем P2
(мимика) и P3 (физика/вторичка).

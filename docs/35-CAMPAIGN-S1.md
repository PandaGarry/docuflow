# 35 · Кампания S1: календарь и брифы

_Тактика: что выходит, когда, на какой площадке, с кем в кадре и каким текстом.
Источник данных — `studio/promo/campaign-s1.json`. Брифы на каждый пост —
`studio/promo/briefs/`, тексты — `studio/promo/copies/all.md`._

## Как этим пользоваться

```bash
.venv/bin/python studio/engine/promo.py plan            # эта таблица из данных
.venv/bin/python studio/engine/promo.py briefs          # пересобрать брифы
.venv/bin/python studio/engine/promo.py copy            # пересобрать тексты
.venv/bin/python studio/engine/promo.py check           # данные не разъехались
```

Правки календаря и текстов вносятся **только** в `campaign-s1.json`: брифы и
подборки текстов генерируются из него и перезаписываются.

## Бриф: что внутри

Открываем `studio/promo/briefs/P10-серия-1-коробки.md` и получаем:

- канал, формат, размер, герои, цель, статус;
- готовый текст (заголовок, тело, CTA, хештеги);
- арт-задание словами;
- **готовый промпт** — копировать целиком, ничего не дописывая;
- список референсов в правильном порядке;
- правила кадра: safe-зоны, лимит слов в заголовке, что перекрывает интерфейс.

## Жизненный цикл поста

```
idea → brief → art → text → ready → published
```

| Статус | Что значит | Кто двигает дальше |
|--------|------------|--------------------|
| `idea` | есть только задумка | автор календаря |
| `brief` | есть промпт, референсы, текст | арт-директор |
| `art` | картинка сгенерирована, приёмку не прошла | арт-директор |
| `text` | арт принят, текст вычитан | редактор |
| `ready` | собрано, проверено `promo.py verify` | публикатор |
| `published` | вышло, стоит дата и метка UTM | публикатор |

Правило: **в `ready` пост попадает только с PASS от `promo.py verify`** и с
пройденным чек-листом приёмки из [`33-PROMO-ART.md`](33-PROMO-ART.md).

## Определение готовности (definition of done)

Пост готов, когда одновременно:

- [ ] картинка собрана в нужном формате и весит ≤ 8 МБ;
- [ ] лица и пропорции совпадают с линейкой семьи;
- [ ] заголовок ≤ 3 строк, читается на 120 px;
- [ ] текст не содержит канцелярита и влезает в лимит площадки;
- [ ] CTA есть и он с причиной;
- [ ] хештеги проставлены (2–3 TG / 3–5 VK / 3 YouTube);
- [ ] метка UTM собрана;
- [ ] файл и текст лежат в репозитории, статус в JSON обновлён.

## Чего в этой кампании нет (сознательно)

- Розыгрышей призов: на старте это приносит «призовых» подписчиков.
- Коллабораций с крупными каналами: сначала нужно 3–4 свои серии.
- Рекламы «на детей»: сериал 12+, таргет на родителей.
- Ежедневных публикаций: темп 3 поста в неделю выдерживается без выгорания.
- Обещаний сезона 2: анонсируем только после 6-й серии.

## Воспроизведение партии

```bash
studio/promo/batch1.sh
```

Собирает P01, P02–P04, P05, P08, P10 из мастеров, печатает совпадение силуэтов
(`proof`), прогоняет `verify` и складывает контакт-лист
`studio/promo/renders/_batch-proof.png`.

Почему так, а не генерацией: см. `docs/34-IDENTITY-LOCK.md`, правило №0.

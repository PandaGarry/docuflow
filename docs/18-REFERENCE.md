# P0. Разбор референсов (эталон → числа)

Этот этап нужен, чтобы слова «сделай как у людей» превратились в параметры,
которые можно проверить на кадре, а не обсуждать на вкус.

## Что нужно от тебя

Положить 2–3 ролика в `studio/reference/` (mp4 / mov / webm, любые по размеру):

1. **эталон стиля** — как должна выглядеть картинка (объём, свет, цвет);
2. **эталон движения** — семейный/комедийный шортс, где нравится анимация;
3. по возможности — **эталон монтажа** (ритм, титры, длина планов).

Файлы не коммитятся (`.gitignore`: `studio/reference/*`), они только для разбора.

## Что я измеряю (автоматически)

```bash
python studio/tools/ref_analyze.py studio/reference/*.mp4 --out docs/18-REFERENCE.md
```

Инструмент даёт по каждому ролику:

| параметр | зачем он нам |
|---|---|
| длительность, размер, fps | формат доставки |
| число склеек, средняя длина плана | ритм монтажа: сколько секунд живёт кадр |
| энергия движения по секундам | темп анимации: где спокойно, где «тряско» |
| крупность (доля высоты кадра под персонажа) и центр по Y | кадрирование: насколько крупно стоят герои |
| палитра (топ-8 цветов с долями) | цветовая база фона/кожи/одежды |
| контактный лист `*-sheet.png` | глазами: позы, ракурсы, мимика |

Дополнительно (вручную по контактным листам, это я делаю и записываю в отчёт):

* **пропорции персонажа**: сколько «голов» в росте, ширина плеч / бёдер в головах,
  длина плеча / предплечья / бедра / голени в долях роста;
* **спектр движений**: какие действия вообще встречаются (шаг, жест, наклон,
  поворот головы) и как часто;
* **спектр эмоций**: какие состояния лица реально используются и с какой
  интенсивностью (спокойно / средне / гротеск);
* **набор форм рта**: сколько viseme видно (по кадрам речи), размер рта
  относительно лица;
* **вторичная анимация**: что «догоняет» (волосы, одежда, живот), на сколько
  кадров отстаёт.

## Выход этапа (чек-поинт)

`docs/18-REFERENCE.md` с числами + таблица «параметр → наше целевое значение» и
контактные листы. Ты смотришь и говоришь: «на это ориентируемся» / «поправь».

Дальше — P1: анатомия одного персонажа (папа) в 3D, с проверкой силуэта против
мастера. Без одобрения P0 персонажа не строю.

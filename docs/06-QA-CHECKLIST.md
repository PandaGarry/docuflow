# 06 · QA: контроль качества и приёмка

Цель — не «поймать баг глазами», а **не пустить его в рендер**. Каждый ассет
и каждый кадр проходят автоматику, затем короткий ручной лист.

## Шлюз 1. Ассеты (автоматика)

```bash
.venv/bin/python studio/engine/qa.py --assets studio/characters studio/assets
```

| Проверка | Как считается | Порог / вердикт |
|----------|---------------|-----------------|
| Разрешение | размер PNG | герой ≥ 900 px по высоте, реквизит ≥ 256 px |
| Альфа-канал | наличие и плотность | есть; площадь силуэта 5–85 % кадра |
| «Дырки» в силуэте | flood fill от края | не больше 2 замкнутых пустот (допустимо: проём между рукой и телом) |
| Ореол по краю | средняя зелень в 2 px вокруг контура | < 8 % пикселей с зелёным сдвигом |
| Число конечностей | профиль ширины силуэта по вертикали | ровно 2 «ножных» экстремума, ≤ 2 «ручных» выступов на уровне корпуса |
| Палитра | ΔE к эталону из библии | средний ΔE < 12, выбросов (> 25) < 3 % |
| Лишние детали | число цветовых кластеров | ≤ 18 кластеров на героя |
| Текст в кадре | детектор «буквоподобных» пятен | запрещён (кроме `ABC` у сына) |

Отчёт: `studio/out/qa-report.md` — таблица «ассет / проверка / статус».
**Красная строка = ассет не идёт в рендер.**

## Шлюз 2. Анатомия в кадре (автоматика + глаза)

Это тот самый класс бага «у мамы три руки». Автоматика помогает, но финальное
слово — за ручным просмотром **каждого шота**:

- [ ] у каждого героя ровно **2 руки и 2 ноги**, 5 пальцев на открытой ладони
- [ ] нет «двойных» кистей, локтей, ушей, глаз
- [ ] борода папы не переходит в шею; чёлка мамы не переходит в бровь
- [ ] кепка `P` и худи `ABC` сына на месте, буква читается
- [ ] цепочка мамы — одна, крестик на месте
- [ ] руки не «врастают» в реквизит, пальцы не проходят сквозь предмет
- [ ] стопы стоят на полу (нет парения и утопания)
- [ ] ни у кого нет «третьей» тени и лишнего источника света

## Шлюз 3. Консистентность между шотами

- [ ] один и тот же герой в разных шотах: совпадает силуэт, причёска, одежда
- [ ] палитра героя в шотах: ΔE между шотами < 8
- [ ] линия одной толщины во всех шотах (4–6 px)
- [ ] фоны одного помещения совпадают по расположению мебели
- [ ] реквизит не «меняет» цвет и размер между шотами

## Шлюз 4. Анимация

- [ ] anticipation есть перед каждым силовым действием
- [ ] follow-through: борода/чёлка/капюшон двигаются после остановки
- [ ] нет «резины» (масштабирование целиком)
- [ ] контакт стопы с полом не скользит
- [ ] мимика не повторяется дважды подряд одинаково
- [ ] липсинк: рот закрыт на паузах, нет «судорог»
- [ ] мигание 2–4 раза за 10 с, не чаще

## Шлюз 5. Монтаж и драматургия

- [ ] крючок в первые 1.5 с (лицо + звук)
- [ ] монтаж 1.5–3 с на план, нет «провисаний»
- [ ] панчлайн на 70–85 % длительности
- [ ] финальный кадр-«нить» на следующую серию
- [ ] длительность 35–45 с (сезон 1)
- [ ] субтитры совпадают со звуком, не перекрывают лица

## Шлюз 6. Техника

- [ ] 1080×1920, 30 fps, yuv420p, H.264 High, `+faststart`
- [ ] звук AAC 192 кбит/с, 48 кГц, стерео
- [ ] громкость −14 LUFS ±0.5, истинный пик ≤ −1.5 dBTP
- [ ] файл декодируется без ошибок (`ffmpeg -v error -i x.mp4 -f null -`)
- [ ] размер файла ≤ 40 МБ
- [ ] SRT сгенерирован и совпадает по таймингу
- [ ] постер снят с самого выразительного кадра

## Шлюз 7. Публикация

- [ ] заголовок и описание содержат «нить» к предыдущей серии
- [ ] обложка (постер) читается в маленьком размере
- [ ] указан дисклеймер: «вымышленная история по мотивам»
- [ ] серия добавлена в `docs/07-SERIES-PLAN.md` с реальной длительностью

## Дефекты и что с ними делать

| Дефект | Причина | Лечение |
|--------|---------|---------|
| Третья рука / лишняя кисть | генерация без референса или перегруженный промпт | перегенерировать с turnaround в референсах; в промпт — явный запрет |
| «Съехало» лицо между шотами | разные промпты на одного героя | один шаблон + один референс на героя |
| Зелёный ореол | chroma key без despill | прогнать `cutout` с despill и blur 1.2 |
| Мыльные края при увеличении | апскейл маленького спрайта | генерировать с запасом ≥ 1.5× от нужного размера |
| Текст на одежде «от модели» | модель дорисовывает | убрать в QA или закрыть цветным пятном |
| Рот «судорога» | минимальная длина визема < 2 кадров | поднять минимум до 2 кадров |

## Роли и подписи

Пока студия «в одном лице», но чек-лист уже разбит по ролям — так проще
передавать задачи: **арт-директор** (шлюзы 1–3), **аниматор** (шлюз 4),
**режиссёр** (шлюз 5), **технический директор** (шлюзы 6–7).

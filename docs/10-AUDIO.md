# 10 · Звук: голоса, музыка, эффекты, громкость

## Голоса

| Герой | Темп | Тон | Манера | Требование |
|-------|------|-----|--------|-----------|
| Папа | 0.95× (чуть медленнее) | низкий, грудной | уверенно, с интонацией «я всё продумал» | 1 голос |
| Мама | 1.0× | средний, тёплый | спокойно, с паузами; усталость в конце фразы | 1 голос |
| Сын | 1.08× (быстрее) | высокий, звонкий | коротко, прямо, без интонации «ребёнок из рекламы» | 1 голос |
| Сосед (с 5-й серии) | 1.0× | средний, «бытовой» | доброжелательно, немного занудно | 1 голос |

Правила:
- **Никакой «мультяшной писклявости»** — она убивает достоверность.
- Детский голос: питч +7 %, темп +5 %, лёгкий де-эссер (иначе свистит на «с/ш»).
- Пауза перед панчлайном — минимум 0.4 с тишины (это работает лучше, чем музыка).

## Обработка реплик

```bash
ffmpeg -i vo.mp3 -af "highpass=f=110,treble=g=1.5:width_type=q:w=0.7,
  acompressor=threshold=-18dB:ratio=2.4:attack=7:release=150:makeup=3" out.wav
```

- Питч: `asetrate=24000*1.07, aresample=48000, atempo=0.945` (сын).
- Лёгкий реверб 0.07–0.09 wet — чтобы «сидело» в комнате, а не в вакууме.
- Нормализация каждой реплики к −3 dBFS пику, затем общий микс.

## Музыка

| Сцена | Характер | Инструменты | Темп |
|-------|----------|-------------|------|
| Быт/диалог | лёгкое пиццикато | укулеле, бас, шейкер | 104–112 |
| Хаос/погоня | ритмичное, с клэпами | укулеле + кик + клэп | 120–128 |
| Пауза перед панчлайном | **тишина** | — | — |
| Финал/тёплый момент | мягкое | пэд, колокольчики | 96 |

Правила:
- Музыка **уходит в тишину** за 0.3 с до панчлайна. Это самый дешёвый способ
  сделать гэг смешнее.
- Гармония: C–G–Am–F (сезон 1), в серии 12 — возврат к C.
- Громкость: музыка −18…−22 LUFS под речью (дакинг −8 дБ на реплике).

## Эффекты (библиотека сезона)

| Эффект | Где | Заметка |
|--------|-----|---------|
| `pop` | появление героя/предмета | 60 мс, питч вверх |
| `whoosh` | переход между шотами | 250–500 мс |
| `thud` | удар/падение | низкий, 90–140 Гц |
| `boing` | пружина/растяжение | синус с вибрато |
| `scratch` | стоп-кадр, «перемотали» | скретч винила |
| `cricket` | неловкая тишина | 3 чириканья |
| `sparkle` | радость/догадка | 4 ноты вверх |
| `creak` | шкаф/дверь | скрип дерева |

Все эффекты синтезируются кодом (`studio/engine/audio.py`) — лицензионных
рисков ноль, повторяемость полная.

## Микс и мастеринг

| Параметр | Значение |
|----------|----------|
| Формат | 48 кГц, стерео, AAC 192 кбит/с |
| Интегральная громкость | **−14 LUFS** (норма соцсетей) |
| Истинный пик | ≤ −1.5 dBTP |
| Диапазон | музыка −20 LUFS, речь −16 LUFS, эффекты −12 LUFS |
| Дакинг | −8 дБ, атака 220 мс, релиз 280 мс |

Проверка:

```bash
ffmpeg -i episode.mp4 -af ebur128=framelog=quiet -f null -
```

## Субтитры

- Формат SRT, 1–2 строки, ≤ 42 знака в строке.
- Появляются за 0.12 с до реплики, исчезают через 0.45 с после.
- Если реплики перекрываются — разносим по времени, не склеиваем в один блок.
- Шрифт задаётся на стороне платформы; мы даём только текст и тайминг.

## Референс по репликам (тон)

| Плохо | Хорошо |
|-------|--------|
| «Дорогая, я всё сделал как надо!» | «Всё. Готово.» (а шкаф качается) |
| «Мама, я тебя люблю» | «Мам. Он опять.» |
| «Я случайно сломал» | «Оно само.» |

Принцип: **чем короче, тем смешнее.** Реплика длиннее 7 слов почти всегда
режется на две серии.

## Синтез музыки в репозитории (`audio.py`)

Стоковые треки не используем: лицензии и Content ID на Shorts. Фоновая музыка
синтезируется кодом — аккорды, бас, перкуссия и мелодия считаются numpy,
экспорт в WAV 48 кГц.

```bash
python studio/engine/audio.py bed --seconds 18.6 --bpm 112 --out studio/out/bed.wav
python studio/engine/audio.py mux --video silent.mp4 --audio bed.wav --out final.mp4
```

Что важно для площадок:

* `loudnorm I=-14 LUFS, TP=-1.5 dBTP` при сборке — ролики не «прыгают» по громкости
  и не клиппуют на телефоне (у промо замер: **-14.6 LUFS**);
* длина трека задаётся монтажом (длительностью сцены), а не «нарезается на глаз»;
* затухание в конце и мягкое начало — без резких стыков;
* стерео — задержкой правого канала (Хаас): шире, но моно-совместимо.

Трек детерминирован (фиксированные зёрна генераторов): повторный рендер даёт тот
же звук — важно, когда видео пересобирается после правок.

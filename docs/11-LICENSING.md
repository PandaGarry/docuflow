# 11 · Лицензии и права

## Что в репозитории и на каких условиях

| Артефакт | Источник | Условия |
|----------|----------|---------|
| Шрифты Montserrat, Nunito | Google Fonts (Fontsource) | SIL Open Font License 1.1, файлы лицензий — `studio/fonts/OFL-*.txt` |
| Код студии (движок, рендер, звук) | написан для этого проекта | используем свободно внутри проекта |
| Музыка и звуковые эффекты | синтезируются скриптом | без сторонних сэмплов, ограничений нет |
| Голоса (TTS) | синтез | проверять условия выбранного провайдера перед публикацией |
| Арт героев, фоны, реквизит | генерация по промптам | правила берём из условий модели, которой генерировали |
| Фото семьи (`studio/reference/`) | личный архив | **не публикуются** и не используются в сериях как есть |

## Права на образы семьи

1. Референсные фото хранятся **только** для дизайна персонажей.
2. В публикуемые серии фото не попадают — только карикатурные герои.
3. Перед публикацией сезона нужно согласие всех взрослых участников (и
   родителя — за ребёнка). Документ простой: «согласны на использование
   карикатурных образов по мотивам в проекте X, отзыв — в любой момент».
4. Если согласие отозвано — герой переименовывается и меняет дизайн-признаки
   (это делается за один проход: промпт-шаблон + палитра).

## Дисклеймер (обязателен в описании каждой серии)

> Вымышленная комедийная история по мотивам. Персонажи — карикатуры, события
> не документальны. Совпадения с реальными бытовыми ситуациями — намеренные.

## Музыка: почему не берём чужие треки

Синтез даёт три плюса: нет страйков на платформах, нет зависимости от
лицензий, трек идеально подстраивается под тайминг (удар точно в склейку).
Единственное ограничение — жанровая простота; для коротких комедий этого
достаточно.

## Шрифты: почему нельзя просто скачать «любой красивый»

Кириллица есть не во всех начертаниях, а лицензии у части шрифтов запрещают
использование в видео без покупки. Используем только SIL OFL — коммерческое
использование разрешено, атрибуция в `docs` уже есть.

## Бренды в кадре

- Не показываем реальные логотипы крупным планом.
- «ABC» на худи сына — нейтральная надпись, не бренд.
- Лампы, коробки, техника — без опознаваемых знаков (или заклеиваем пятном).

## Хранение и приватность

- Фото семьи — только в `studio/reference/`, без индексации; при публикации
  репозитория эту папку можно убрать в приватное хранилище.
- Голосовые сэмплы детей не публикуются в открытом доступе без согласия.
- Метаданные видео очищаем: без GPS и имён файлов с личными данными.

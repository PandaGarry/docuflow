# 3D-ветка: почему свой рендерер и как он устроен

## Решение

Мы переходим с 2D-cutout (один фронтальный рисунок + mesh-warp) на **настоящую
3D-геометрию со своим программным рендерером**. Причина простая: варп плоского
рисунка не создаёт объём — он тянет пиксели. Из этого выросли все видимые
дефекты: «резиновые» бёдра, ломаные плечи, рот-наклейка, косые руки.

## Почему не Blender

`bpy` ставится из PyPI, но **не запускается в песочнице**: нужны системные
X11-библиотеки (`libXrender.so.1`, `libXi`, `libGL`), apt-пакетов в образе нет,
а сеть открыта только на pypi/github/npm. Проверено:

```
ImportError: libXrender.so.1: cannot open shared object file
```

Поэтому — свой рендерер `studio/engine/render3d.py` на numpy. Плюсы: нулевые
зависимости, полный контроль над стилем, детерминированный результат,
воспроизводимость в любой среде.

## Как устроено

* **Сетка** (`Mesh`): вершины, треугольники, нормали, цвет вершин, AO,
  признак отсечения задних граней. Примитивы: `sphere`, `capsule`, `box`,
  `merge`, `transformed` (аффинно, с пересчётом нормалей).
* **Растеризация**: перспективная камера (`Camera`), z-буфер, барицентрика по
  площадям, отсечение задних граней по сглаженным нормалям (не по порядку
  обхода — иначе видно изнанку), батчи по размеру треугольника (мелкие не тянут
  буфер на весь кадр), суперсэмплинг с премультиплицированной альфой.
* **Свет** (`Lights`): hemisphere (небо/земля) + ключевой с wrap-диффузом +
  холодный заполняющий + контровой rim; AO по вершинам. Это и даёт «объёмный»
  вид стиля B без фотореализма.
* **Производительность** (2 ядра): 480×640 ss=2 — **0.58 с/кадр**;
  720×1280 ss=2 — около **2 с/кадр**. Для 10-секундного шота (240 кадров) это
  ~8 минут — нормальный цикл итерации.

## Что появится дальше

1. `studio/engine/body3d.py` — параметрическое тело по анатомическим ориентирам:
   рост в головах, ширина плеч/бёдер, длины сегментов, объёмы; всё — числа из
   `character.json`, никакого «на глаз».
2. Проверка пропорций: рендер вида спереди сравнивается с `views/front.png`
   по силуэту (IoU) и по ключевым отношениям (плечи/бёдра/голова).
3. Скелет 18–22 кости + веса (по сегментам, с мягким стыком), позы из IK.
4. Лицо: глазные яблоки + веки, ротовая полость с зубами и языком, morph-таргеты
   viseme (А/Э/И/О/У/М/Ф) и эмоций; сходство с мастером — через текстуру/рельеф
   лица, снятый с `views/front.png`.
5. Вторичная анимация: волосы/одежда/живот как «догоняющие» слои, breathing,
   blink, лаг головы.

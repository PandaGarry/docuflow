# 32 · Голос и тексты

_Как звучит сериал в тексте: правила, формулы заголовков, структура постов по
площадкам, хештеги, ответы в комментариях. Готовые 26 текстов —
`studio/promo/copies/all.md` (источник: `studio/promo/campaign-s1.json`)._

## Кто говорит

Голос проекта — **взрослый, который устал, но любит**. Не «бренд», не «ведущий
детской передачи», не «саркастичный аниматор». Это человек, который уже пережил
переезд и теперь может рассказать о нём спокойно, с одной шуткой на абзац.

| Есть | Нет |
|------|-----|
| короткие фразы | длинных сложноподчинённых периодов |
| конкретика: числа, предметы | оценок: «забавно», «увлекательно» |
| ирония без злобы | сарказма над зрителем |
| тепло без сиропа | «дорогие друзья» |
| недосказанность в конце | морали и объяснений, что смешно |

## Шесть правил

1. **Одна мысль — одно предложение.** Если в предложении два «и», это два предложения.
2. **Конкретика вместо оценки.** «25 винтов на столе», а не «нелепая ситуация».
3. **Шутка — в конце.** Сначала факт, потом поворот. Не наоборот.
4. **Никакой морали.** Мы не объясняем, почему смешно, и не делаем выводов за зрителя.
5. **Текст про зрителя, а не про нас.** «Вы уже видели это в своей жизни» сильнее,
   чем «мы нарисовали смешную сцену».
6. **Ноль восклицательных знаков** — норма. Один на пост — допустимо. Два — уже крик.

## Эмодзи

0–2 на пост, только как смысловой знак, не как украшение.
Разрешено: 👇 (ссылка ниже), 🙂 (самоирония), 🤝 (спасибо), 🔥 — редко.
Запрещено: 🎬 🚀 ✨ 🎉 💫 🍿 и любые ряды из трёх и больше.

## Запрещённые слова и приёмы

- Канцелярит: *уникальный, инновационный, качественный контент, синергия, эксклюзив*.
- Маркетинговый шум: *мы рады сообщить, не пропустите, скорее, успейте, лучший*.
- Ложный кликбейт: *вы не поверите, что было дальше* (и не показываем).
- Обещания качества: *самый смешной мультсериал*.
- Англицизмы без нужды: *челлендж, дроп, контент-план, воркшоп*.
- CAPS LOCK целыми словами и «!!!».
- Обращение «друзья!» — мы не клуб, мы канал.
- Любая личная информация о реальной семье.

`promo.py check` ловит часть этих слов автоматически и валит проверку.

## Формулы хуков (первая строка)

Первая строка решает, дочитают ли. Десять рабочих схем:

| # | Схема | Пример |
|---|-------|--------|
| 1 | число + предмет | «25 винтов на столе» |
| 2 | признание | «Мы пересняли этот кадр четыре раза» |
| 3 | вопрос-узнавание | «У вас тоже остаётся «запасная» деталь?» |
| 4 | цитата героя | «Тут написано: соберите вдвоём» |
| 5 | обещание конфликта | «Папа уверен, что справится за вечер» |
| 6 | противопоставление | «Один переезд, три взгляда» |
| 7 | микро-история | «Коробку распаковали. Одну» |
| 8 | правило с изъяном | «Правило переезда №1: коробки распакуются сами» |
| 9 | дата/дедлайн | «16 ноября — премьера» |
| 10 | самоирония | «Мы делаем мультсериал про свою семью. Да, мы в курсе» |

Правило: **хук не врёт.** Если в первой строке винт — винт должен быть на картинке.

## Структура поста по площадкам

### Telegram
```
1 строка — хук (≤ 60 знаков, видно в превью)
пустая строка
2–4 коротких абзаца (всего ≤ 700 знаков)
пустая строка
CTA одной строкой
2–3 хештега
```
Лимит подписи — 1024 знака (проверяется `promo.py check`).

### VK
```
1–2 строки — хук (видно в превью «показать полностью»)
тело ≤ 600 знаков, абзацы по 1–2 строки
CTA + ссылка
3–5 хештегов
```
VK не любит «стену»: 600 знаков читаются, 2000 — пролистываются.

### YouTube Shorts
```
Название: «Серия N. Название» ≤ 60 знаков
Описание: 2–3 строки, первая — хук, вторая — что внутри, третья — ссылка
3 хештега (первый — #shorts)
```

### Сторис / кадры-титры
3–5 слов на кадр, не больше. Текст читается за 1 секунду.

### Rutube / Дзен
Тот же текст, но абзацы можно длиннее и обязательна подпись к картинке
(там превью живёт отдельно от поста).

## CTA-библиотека

CTA всегда с причиной. «Подпишитесь» без причины не работает.

| Тип | Формулировка |
|-----|--------------|
| подписка через дедлайн | «Подпишитесь — премьера 16 ноября, потом искать будете дольше» |
| комментарий | «Пишите, что нашлось у вас под диваном» |
| пересылка | «Отметьте того, кто «всё продумал»» |
| сохранение | «Сохраните: пригодится на следующем переезде» |
| просмотр | «Серия 2 — 40 секунд» |
| обсуждение | «Кто прав?» |

## Хештеги

- Постоянные (в каждом посте): `#мультсериал` `#переезд` `#анимация` — берём 2 из 3.
- Тематические по серии: `#коробки` `#шкаф` `#соседи` `#пицца` `#ремонт`.
- Платформенные: `#shorts` (YouTube), `#мем` (VK).
- Сколько: Telegram 2–3, VK 3–5, YouTube 3. Больше — выглядит как спам.

## Тон в комментариях

Правила: отвечаем на всё в первые 2 часа после публикации; не спорим; не удаляем
критику; не раскрываем детали реальной семьи; благодарим за «это про меня».

| Ситуация | Ответ |
|----------|-------|
| «Это про меня» | «Значит, вы тоже распаковали одну коробку и легли» |
| «А когда следующая?» | «В понедельник. Серия про шкаф, там будет винт» |
| «Почему так мало?» | «40 секунд — это три шутки. Больше — уже не шутки» |
| «Мультик для детей?» | «12+. Дети смотрят, но шутки про ипотеку — для вас» |
| Критика анимации | «Согласны, кадр сырой. Переснимем — покажем» |

Не отвечаем: на политику, на «а почему у героев нет...», на провокации.
Один нейтральный ответ и закрываем тему.

## Что нельзя публиковать

- Реальные фотографии семьи, адреса, имена, возраст детей, место работы.
- Формулировку «это точная история нашей семьи» — сериал вымышленный
  (см. [`11-LICENSING.md`](11-LICENSING.md)).
- Фото и истории подписчиков без письменного разрешения (UGC, P24).
- Обещания сроков, которые не выдержим: лучше «следующая — в понедельник»,
  чем «скоро».

## Как писать новый пост: 4 шага

1. Выбери **сегмент** (родители / любители анимации / семейные чаты).
2. Выбери **тип** (гэг, знакомство, бекстейдж, серия, интерактив).
3. Возьми **формулу хука** из таблицы — не придумывай заново.
4. Проверь: нет ли канцелярита и второго восклицательного; влезает ли в лимит
   площадки (`promo.py check`).

## Словарь проекта

Чтобы тексты звучали одинаково, используем одни и те же слова:

| Пишем | Не пишем |
|-------|----------|
| серия | эпизод, выпуск |
| шортс / короткая серия | клип, ролик |
| герой | персонаж (в текстах для зрителя) |
| кадр | фрейм, шот |
| переезд | релокация |
| рамка, винт, коробка | «реквизит», «проп» |

Имена героев в текстах для зрителя: **Папа, Мама, Сын**. Не имена, не «отец
семейства». Когда появятся «сериальные» имена — меняем здесь и в
`studio/promo/canon/identity.json`, промпты подтянутся сами.

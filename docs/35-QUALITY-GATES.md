# 35 · Шлюзы качества и приёмка анимации

**Дата:** 2026-11-02 · **версия:** 1.0. Значения ниже — стартовые проектные
допуски, не результаты уже выполненных измерений и не отраслевой стандарт.
Изменять их можно только с записью причины в decision log до повторной приёмки.

## Общие правила

1. Технический pass и художественное одобрение — разные поля. Одно не заменяет другое.
2. У каждого отчёта — revision модели/рига/аудио/сцены и проверяемый артефакт.
   «Выглядело хорошо в прошлой версии» не переносит approval на новую.
3. Метрики считаются на defined sample set, а не на одном удобном кадре.
4. Нельзя скрывать стопы монтажом при проверке походки или скрывать рот
   субтитрами при проверке lipsync. Крупный план обязателен.
5. Просмотр в реальном времени со звуком — обязательный. Стоп-кадр не ловит
   ритм, рассинхрон и temporal flicker.
6. Эвристика `qa.py` не доказывает правильное число пальцев/конечностей.
   Генеративные ассеты и деформации требуют художественной проверки.

## G0 · План и подтверждённый стартовый срез

**Выход:** актуальные план, архитектура, критерии, план-задачи, снимок среды.
Статусы не приписывают реализованность проектируемым модулям. Генерация
чек-листа повторяема, ссылки на evidence существуют, DAG зависимостей корректен.
Это gate документации/учёта, не готовность runtime.

## G1 · Исполнимая среда и backend

**Частично подтверждено:** [реальный 24-кадровый smoke](38-BLENDER-MVP.md)
прошёл 14 проверок. Отмеченные пункты относятся к техническому MVP, не к
производству семейной серии. Общий G1 не закрыт: PIPE-01/02 и ENV-04 ещё открыты.

- [x] Зафиксированы Blender build, Python/dependencies, FFmpeg и color config.
- [x] Headless worker создал тестовую сцену с armature, IK, shape key и светом.
- [x] Отрендерены 24 последовательных кадра 1920×1080, 24 fps, без пропусков.
- [x] Собран и полностью декодирован H.264/AAC MP4; проверены кодеки и frame count.
- [x] Описаны устройство, memory budget, wall time, peak RAM; GPU только если проверен.
- [x] Ошибка backend завершает job с ненулевым кодом; нет подмены PNG-превизом.
- [ ] Контракты внешнего production model/rig package валидируются; отсутствующий
  asset/channel вызывает понятную ошибку, probe не подставляется вместо модели.
- [ ] Проверена поддерживаемая OS/base image без экспериментального native mirror;
  пройдены integrity/security review и длинный memory-bounded stability test.

**Блокер:** нет renderer/кодека/нужных библиотек либо smoke test не проходит.
Не строить план на неподтверждённом ускорении и не устанавливать платную
инфраструктуру без согласования.

## G2 · Канон и пригодная для деформации модель

**Набор просмотра:** нейтральный полный рост фронт/3/4/профиль/спина,
turntable, лицо крупно, кисти и обувь отдельно. Взрослый/ребёнок не должны
получать усреднённые пропорции.

- [ ] Пользователь принял внешний вид конкретной revision.
- [ ] Один меш/пакет сохраняет форму между ракурсами; нет новых случайных лиц.
- [ ] Присутствуют полость рта, зубы/язык, веки, закрытая геометрия скрытых участков.
- [ ] Проверены нормали, веса, rest pose, scale и отсутствие непреднамеренных
  non-manifold/пересечений в деформируемой геометрии. Допустимые открытые детали
  или наложение одежды перечислены явно, а не скрыты общей проверкой manifold.
- [ ] Источник, права/лицензия и hashes записаны; личные фото не опубликованы.

Численная сверка пропорций проводится в одной ortho-камере и единицах, не
по перспективным скриншотам. Запрещена нормализация каждого кадра своим ростом,
которая скрывает изменение масштаба персонажа.

## G3 · Тело, походка, жесты и контакт

**Тесты:** rest, плечо вверх/вперёд, локоть согнут, присед, шаг, старт и
остановка, указание, касание бороды/кепки; фронт/3/4/профиль. Кадры проверяются
в движении и покадрово в местах контакта.

Стартовые метрики при высоте персонажа H в метрах:

| Метрика | Допуск / способ |
|---|---|
| Непреднамеренное изменение длин костей | ≤ 0,1% от rest; intentional squash имеет отдельный профиль |
| Проскальзывание опорной стопы | max ≤ 0,5% H за один размеченный stance interval |
| Высота плоской опорной подошвы над полом | абсолютная ошибка ≤ 0,3% H; toe/heel roll проверяется по своей contact точке |
| Проникновение contact point под поверхность | ≤ 0,2% H численного допуска; видимые пересечения — fail независимо от числа |
| Ошибка кисти на hold контакта | max ≤ 0,5% H относительно целевой поверхности |
| NaN/Inf, непреднамеренные flips IK, оторванные части | 0 |

Slip считается в системе контактной поверхности, не экрана и не движущегося
root. Исключены вход/выход контакта по размеченным boundaries; интервалы и
правила публикуются вместе с отчётом, не подбираются после результата.
Разная длина ноги или неподходящая походка ребёнка — художественный fail,
даже когда математический IK попадает в цель.

## G4 · Лицо и живость без речи

**Тесты:** нейтральность, улыбка, недоумение, понимание, смех, взгляд по цели,
одиночное/двойное моргание, полное закрытие глаз и губ. Фронт и 3/4.

- [ ] Веки закрываются геометрически, не прозрачностью радужки.
- [ ] Глаз не вылезает сквозь веко, взгляд не косит случайно.
- [ ] Челюсть, зубы, губы и борода связаны; нет второго подбородка или рта.
- [ ] Сочетания улыбки/челюсти/закрытия губ проверены, shape weights ограничены.
- [ ] Реакция имеет смысловой beat и паузу; нет постоянной дрожи и одинаковой
  синусоиды у всех героев.
- [ ] Нет внезапной смены лица/масштаба головы на соседнем кадре.

Набор выражений считается принятым только после просмотра пользователя;
автоматическая оценка «эмоции узнаваемы» не выдумывается.

## G5 · Артикуляция по фактическому аудио

**Набор:** минимум три реплики одного утверждённого голоса — медленная,
обычная и быстрая, с /п, б, м/, /ф, в/, /а, о, у, и/ и паузами. Transcript
должен совпадать с записью; разметка привязана к её checksum.

- [ ] Phone spans получены проверенным aligner либо вручную; текстовое
  распределение букв и amplitude-only jaw не принимаются за полноценный lipsync.
- [ ] Проверены все bilabial closures и не менее 20 суммарных переходов между
  формами рта. Если в трёх репликах переходов меньше — добавить материал.
- [ ] Не менее 90% проверенных closure landmarks попадают в ±1 кадр относительно
  вручную подтверждённой целевой визуальной разметки на 24 fps; максимум ±2 кадра.
- [ ] Целевая разметка учитывает естественное опережение артикуляции: не все
  фонемы требуют максимального открытия ровно в акустическом onset.
- [ ] В паузах рот возвращается в осмысленную позу, /п, б, м/ смыкают губы,
  /ф, в/ используют губу/зубы, а не случайную гласную.
- [ ] Коартикуляция сглаживает переходы без «болтанки» зубов/языка и без
  подавления обязательного смыкания при улыбке.
- [ ] Читаемая речь во фронте/3/4, целый диапазон челюсти, ноль оторванных губ.

Отчёт сохраняет ручные landmarks, предсказанные времена, residuals в кадрах,
число событий и версии разметки. Не заявлять точность автоматического aligner
по его собственному выводу без независимой проверки.

## G6 · Соло-срез: 8 секунд

Папа: старт → два шага → остановка → реплика → жест. Полный рост и крупный
план на той же модели. Примерный объём 192 кадра при 24 fps; длина фиксируется
в контракте до записи. G1–G5 и зависимости задачи должны быть закрыты.

- [ ] Реальная непрерывная смена позы, а не монтаж вместо подъёма руки.
- [ ] Видны ноги, перенос веса, остановка и плечо/локоть/кисть.
- [ ] Речь, взгляд и жест образуют одну актёрскую мысль.
- [ ] Пользователь принял кандидата по просмотру, замечания записаны и закрыты.

Прохождение численных тестов без этого просмотра не закрывает G6.

## G7 · Два героя: 12 секунд

Та же система: папа действует, сын смотрит и реагирует лицом на смысл реплики.
Сын имеет собственную принятую геометрию/лицевой риг, а не вклеенную картинку.
Проверяются масштаб, eyeline, 180-degree staging, timing реакции и отсутствие
«все смотрят в камеру». Утверждается конкретная revision кандидата.

## G8 · Первая полноценная короткая серия и выпуск

- [ ] У всех действующих героев приняты модели, риги и нужные действия.
- [ ] Приняты сценарий, dialogue edit, blocking, animation polish и lighting.
- [ ] Финал 1920×1080, 24 fps; для 40 секунд — ровно 960 видеокадров.
- [ ] Master mix 48 kHz, длительность/offset согласно контракту; нет дрейфа.
- [ ] Delivery mix: целевой integrated loudness −16 LUFS ±1 LU,
  true peak ≤ −1 dBTP после финального кодирования; измерение, не только фильтр.
- [ ] Ноль пропусков/дублей по ошибке сборки, яркостных вспышек, шумового
  мерцания денойзера, чужих теней и видимых пересечений.
- [ ] Color config закреплён; стилизация blur/DOF не скрывает дефекты анимации.
- [ ] Субтитры в safe area, звук разборчив, есть MP4/SRT/poster/manifest/QC.
- [ ] MP4 полностью декодирован, hashes совпадают; воспроизведение проверено
  на целевом устройстве. Если устройство не проверено — так и записано.
- [ ] Clean rebuild на заявленном worker воспроизводит шот по manifest.
  Между разным GPU/денойзером не обещается побайтовое совпадение без теста.
- [ ] Пользователь принял финал. Лишь затем разрешён статус publish-ready.

## Хранение доказательств

Обычный Git: спецификации, код, компактные тестовые fixtures, manifest,
краткий отчёт, approval record. Большие модельные веса, frame passes и
промежуточные видео — игнорируемый cache/внешнее хранилище с hash. Текущая
политика `studio/out/` сохраняется; добавление нового финала в исключения
`.gitignore` — явное решение выпуска, не обход через бесконечный `git add -f`.

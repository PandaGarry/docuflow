not a new design reset. First R5 native colors were inspected before completion:
ears improved, but lip pigment overspilled above the vermilion, skin looked pale
beige, iris too blue. All R5 native recipes/evidence remain frozen.

stored as attached color alpha and connected to Roughness, **not opacity**.

# Mom R6 — correct actual first-color problems

This is a direct continuation of the user's ear/likeness/canonical-color request,
not a new design reset. First R5 native colors were inspected before completion:
ears improved, but lip pigment overspilled above the vermilion, skin looked pale
beige, iris too blue. All R5 native recipes/evidence remain frozen.

R6 keeps the smaller ears and R5 face/brow/eye design. Only lower-lip volume
receives0.7mm inward/up offsets. Attached lip pigment now has an explicit
source-rest external-surface upper/lower chart, clipped by deform weights and
feathered at the border: paired peaks/central valley rather than broad painted
trapezoid. Mesh attribute follows native deformations. This is not render retouch.

Skin albedo remains based on canonical#E8B48F with warmer front complexion,
stronger soft cheek/nasal warmth; iris ramp retains gray-blue#73879A direction
with lower chroma. Brows deeper brown. Lip roughness0.34 versus skin0.47 is
stored as attached color alpha and connected to Roughness, **not opacity**.
AgX/light response means palette values are not displayed-pixel guarantees.

Native build/reopen and new visual review pending. The technical R5 persistence
pass did not establish good color, exact likeness or complete face/acting.
Known blink failure/full facial rest migration/hair/body/wardrobe remain open;
art/user/production-swap approvals remain false. Private inputs not read/published.

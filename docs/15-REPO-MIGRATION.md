# 15 · Переезд в репозиторий `family_studio`

## Что выяснилось

- Репозиторий `PandaGarry/family_studio` **существует**, но он **приватный**.
- Мой GitHub-доступ (GitHub App) видит только публичные репозитории и не имеет
  прав на этот: чтение возвращает `403 Resource not accessible by integration`.
- Поэтому автоматически переподключиться к нему я пока не могу: нужен доступ.

## Вариант 1 (лучший): дать доступ

Выберите любое:

1. **Пригласить GitHub App в репозиторий.** В настройках GitHub App
   (Settings → Applications/Integrations → Arena) добавить `family_studio`
   в список доступных репозиториев. После этого я смогу пушить напрямую.
2. **Сделать репозиторий публичным** на время (Settings → Danger Zone →
   Change visibility) — тогда я смогу читать и пушить сразу, а приватность
   вернёте в один клик.
3. **Передать права через нового владельца/коллаборатора** — если у вашего
   аккаунта и у подключения один и тот же пользователь, достаточно пункта 1.

Как только доступ появится — скажите, и я:
переключу `origin` на новый репозиторий, запушу ветку, открою PR уже в нём,
и продолжу работу без остановок.

## Вариант 2 (сейчас, без доступа): перенести содержимое сами

В репозитории лежит скрипт, который переносит ветку в ваш новый репозиторий
одной командой (запускается на вашей машине, где есть доступ к обоим):

```bash
bash studio/tools/sync_to_repo.sh git@github.com:PandaGarry/family_studio.git
```

Он клонирует публичный репозиторий со веткой студии, добавляет ваш новый
репозиторий как remote и пушит туда ветку и `main`. Секретов и токенов в
скрипте нет — только адреса.

## Вариант 3: остаться здесь и переименовать

Если доступ дать не получается — оставляемся в текущем репозитории и
переименовываем его вручную: **Settings → Repository name → `family_studio`**.
GitHub автоматически перенаправит старые ссылки; вся структура внутри уже
готова и от имени не зависит.

## Что не надо переносить

- `studio/reference/` — личные фото семьи. В приватном репозитории это
  нормально, в публичном — уберите (`docs/11-LICENSING.md`).
- `studio/out/*.wav` и превью-кадры — пересобираются скриптами (уже в `.gitignore`).

# 05 · Анимация: как получается «живая» картинка

Проблема прошлого ролика: персонаж целиком масштабировался и подпрыгивал —
это читается как «шевелящаяся картинка». Живость даёт не количество кадров,
а **иерархия движения**: корпус ведёт, конечности догоняют, мелочи (волосы,
капюшон, живот) живут своей жизнью.

## 1. Риг: скелет и IK

Каждый герой собирается из слоёв (голова, шея, корпус, плечи, предплечья,
кисти, бёдра, голени, стопы, волосы, одежда) и получает скелет:

```
root
└─ hips ─ spine ─ chest ─ neck ─ head ─ (hair, brows, eyes, jaw)
   │                  ├─ shoulder.L ─ upper_arm.L ─ forearm.L ─ hand.L
   │                  └─ shoulder.R ─ upper_arm.R ─ forearm.R ─ hand.R
   ├─ thigh.L ─ shin.L ─ foot.L
   └─ thigh.R ─ shin.R ─ foot.R
```

**Почему IK, а не углы.** Аниматор задаёт цель: «кисть к чашке», «стопа на
пол». Двухзвенный IK считает локоть/колено сам, и рука не «выворачивается» —
именно эта ошибка чаще всего ломает кадры в cut-out-анимации.

Что уже реализовано в `studio/engine/rig.py`:

| Возможность | Что даёт |
|-------------|----------|
| Иерархия костей + мировые/локальные трансформы | поворот корпуса тянет руку, а не наоборот |
| Двухзвенный IK (локоть/колено) с полюсным вектором | корректные суставы без выворотов |
| Ключи + интерполяция (linear/ease/back/spring) | управляемая динамика между позами |
| Spring-цепочка для волос и капюшона | вторичная анимация «сама», от движения головы |
| Сквош-стретч с сохранением объёма | удар/прыжок без «резинового» вида |
| Мигание и липсинк по виземмам | лицо живёт независимо от тела |

## 2. Двенадцать принципов — что применяем и где

| Принцип | Применение в сериале |
|---------|----------------------|
| Anticipation | папа замирает на 4 кадра перед тем, как поднять шкаф |
| Squash & stretch | приземление, удар, «спружинил» на диване |
| Staging | лицо и руки всегда в одной зоне, силуэт читаем |
| Straight ahead / pose to pose | основной ход — pose-to-pose по ключам, мелочи — straight ahead |
| Follow through | борода, чёлка, капюшон, живот продолжают движение на 3–6 кадров |
| Slow in / slow out | все основные кривые — ease-in-out, кроме комедийных «щелчков» |
| Arcs | кисть/стопа двигаются по дуге, а не по прямой |
| Secondary action | мама вздыхает, пока папа говорит; сын ковыряет нос |
| Timing | быстрые удары 2–3 кадра, реакции 6–10 кадров, пауза перед панчлайном ≥ 12 кадров |
| Exaggeration | брови папы ×1.4 от реальной амплитуды, глаза мамы ×1.2 |
| Solid drawing | объём сохраняется при повороте: слои имеют «толщину» через 2-3 подслоя |
| Appeal | у каждого героя своя «поза-визитка» в кадре |

## 3. Базовые циклы (делаются один раз на сезон)

| Цикл | Кадров | Замечания |
|------|--------|-----------|
| Idle | 60 (2 с) | дыхание 0.25 Гц, микро-сдвиг головы, мигание каждые 3–5 с |
| Walk | 24 (0.8 с) | контакт → вниз → проходка → вверх; руки в противофазе |
| Run | 16 | наклон корпуса 12°, больше амплитуда, борода «отстаёт» |
| Talk | 12 | корпус + голова + жесты рук, рот — от липсинка |
| React (surprise) | 10 | anticipation 3 кадра → распахнутые глаза → отскок назад |

## 4. Липсинк

1. Текст → фонемы (правила для русского: оглушение, редукция безударных).
2. Фонемы → 6–8 визем (`A, E, I, O, U, M, F, L`).
3. Виземы → кадры: длительность пропорциональна фонеме, но минимум 2 кадра,
   иначе «дрожание» рта.
4. Сглаживание: смешиваем соседние формы рта на 1 кадр.
5. Синхрон: рот закрывается на паузах и на знаках препинания.

Проверено на слух правило: **лучше 6 чётких форм рта, чем 20 «плывущих»**.

## 5. Бюджет движения на шот

| Длительность шота | Минимум событий | Пример |
|-------------------|-----------------|--------|
| 1.5 с | 1 действие + 1 реакция | схватил коробку → посмотрел |
| 2.5 с | 2 действия + мимика | открыл → заглянул → удивился |
| 3.5 с | 3 действия + пауза | поднял → понял → медленно поставил |

Если событий меньше — шот вырезается или укорачивается. Пустой кадр в шортсе
стоит дороже, чем недоделанный гэг.

## 6. Чего избегаем (типовые баги)

- **Резиновый герой:** масштабируется весь персонаж целиком.
- **Плавающие ступни:** стопа не зафиксирована IK на полу.
- **Мёртвые руки:** руки не меняют позу, пока корпус двигается.
- **Непрерывное мигание:** мигание чаще 2 раз в 3 с выглядит как тик.
- **Скольжение:** походка без фиксации контакта — герой «едет» по полу.
- **Слишком быстрый липсинк:** рот меняется каждый кадр, читается как судорога.

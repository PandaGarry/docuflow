# 02 · Пайплайн производства

Один цикл = одна серия. Слева — этап, справа — артефакт, который остаётся
в репозитории (его можно проверить, откатить и пересобрать).

```
0. Идея        →  docs/07-SERIES-PLAN.md  (карточка серии)
1. Сценарий    →  studio/episodes/ep01.json  (шоты, реплики, тайминг)
2. Арт         →  studio/characters/*, studio/assets/*  (PNG-слои)
3. QA арта     →  studio/out/qa-report.md  (авто + ручной лист)
4. Риг/анимация→  studio/episodes/ep01.anim.json  (кривые, позы)
5. Озвучка     →  studio/assets/audio/vo_*.mp3
6. Липсинк     →  studio/episodes/ep01.lipsync.json
7. Музыка/звук →  studio/assets/audio/mix.wav
8. Рендер      →  studio/episodes/ep01.mp4 + .srt + poster.jpg
9. Приёмка     →  галочки в docs/06-QA-CHECKLIST.md
```

## Этап 0. Идея (15 минут)

Из сезонной карточки (`docs/07`) берём: завязку, поворот, панчлайн, «нить» в
следующую серию. Если панчлайн не формулируется одной фразой — идея сырая.

**Выход:** 5 строк в карточке серии.

## Этап 1. Сценарий и шот-лист (30–60 минут)

Пишем в JSON, а не в текстовом редакторе: тайминг сразу машинно проверяемый.

```jsonc
{
  "id": "ep01",
  "title": "Коробки",
  "fps": 30, "size": [1080, 1920], "duration": 40.0,
  "characters": ["dad", "mom", "son"],
  "props": ["box_a", "box_b", "tape_roll"],
  "shots": [
    {"id": "s1", "start": 0.0, "dur": 3.2, "bg": "living_day",
     "camera": {"zoom": [1.05, 1.14], "anchor": [0.5, 0.55]},
     "actors": [{"who": "son", "pose": "point", "x": 0.5, "y": 0.88, "h": 0.45}],
     "dialogue": [{"who": "son", "text": "Пап, а куда мы переехали?", "t": 0.4}]}
  ]
}
```

Обязательные проверки схемы (`engine/timeline.py --validate`):
шоты не перекрываются, сумма длительностей = `duration`, у каждой реплики есть
тайминг, у каждого персонажа в кадре — валидная поза из библии.

## Этап 2. Арт (1–2 часа на серию)

1. **Turnaround-листы** героев (фронт/3-4/профиль/спина) — генерируются один
   раз, переиспользуются весь сезон.
2. **Позы**: для каждой сцены — нужные позы из набора (idle, walk, talk, point,
   surprise, smug, think, carry).
3. **Липсинк-набор**: 6–8 форм рта на героя.
4. **Фоны**: 2–3 на серию, с оверсканом 15 % под движение камеры.
5. **Реквизит**: коробки, скотч, шкаф — отдельными PNG.

Правила генерации — в `09-PROMPT-COOKBOOK.md`. Ключевое: **один герой = один
промпт-шаблон + один референс + одна палитра**, свободы для «третьей руки» нет.

## Этап 3. QA арта (10 минут, обязательный шлюз)

```bash
.venv/bin/python studio/engine/qa.py --assets studio/characters studio/assets
```

Автопроверки: альфа-контур, «дырки» внутри силуэта, число конечностей по
профилю ширины, палитра (ΔE к эталону), разрешение, ореол по краю.
Отчёт → `studio/out/qa-report.md`. Красная строка = ассет не идёт в рендер,
пока не перегенерирован. Ручной лист — `06-QA-CHECKLIST.md`.

## Этап 4. Риг и анимация (1–3 часа на серию)

- Поза задаётся **целевыми точками** (кисти, стопы, голова) — IK сам считает
  сгибы локтей и коленей. Аниматор думает «куда тянется рука», а не «угол
  плеча 37°».
- Между позами — интерполяция по кривым: `ease-in-out` для основного движения,
  `ease-out-back` для появлений, `spring` для вторичной анимации.
- Обязательные принципы на каждый шот: **anticipation** перед действием,
  **follow-through** после, **overlapping action** (голова позже корпуса),
  **второй план** (волосы, капюшон, живот).
- Мигание и липсинк — процедурно, по таймингу реплик.

## Этап 5–7. Звук (40 минут)

1. Реплики: TTS (2 голоса) → нормализация, де-эссер, лёгкий реверб.
2. Музыка: синтез под сцену (укулеле/пиццикато + бас + шейкер), громкость по
   интенсивности сцены.
3. Эффекты: whoosh на переходах, импакты на склейках, «мультяшные» акценты.
4. Микс: дакинг музыки под голос, мастер `loudnorm I=-14 TP=-1.5`.

## Этап 8. Рендер (3–6 минут)

```bash
.venv/bin/python studio/engine/render.py --episode studio/episodes/ep01.json
```

Выход: `ep01.mp4` (1080×1920, 30 fps, H.264 High, `+faststart`),
`ep01.srt`, `poster.jpg`.

## Этап 9. Приёмка

Чек-лист `docs/06-QA-CHECKLIST.md` целиком. Если хоть один пункт «нет» —
серия не публикуется. Это дешевле, чем ловить «третью руку» в комментариях.

## Тайминг производства к концу сезона

| Этап | Серия 1 | Серия 6 | Серия 12 |
|------|---------|---------|----------|
| Идея + сценарий | 90 мин | 45 мин | 30 мин |
| Арт (новые ассеты) | 3 ч | 1 ч | 40 мин |
| QA | 30 мин | 15 мин | 10 мин |
| Анимация | 4 ч | 2 ч | 1.5 ч |
| Звук | 60 мин | 40 мин | 30 мин |
| Рендер + приёмка | 30 мин | 20 мин | 20 мин |
| **Итого** | **~10 ч** | **~5 ч** | **~3.5 ч** |

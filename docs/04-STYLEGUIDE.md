# 04 · Стайлгайд

Документ фиксирует визуальные правила, чтобы серия 12 выглядела как серия 1.
Эталон выбирается из тестов в `studio/style-tests/` — до выбора стиля
действуют общие правила (они не зависят от варианта).

## Структура кадра (9:16, 1080×1920)

```
┌─────────────────────┐
│ safe-top 120 px     │  ← ничего важного (интерфейс соцсетей)
│                     │
│   зона действия     │  ← 70 % кадра, лица в верхней трети
│                     │
│ safe-bottom 260 px  │  ← субтитры, графика, интерфейс
└─────────────────────┘
```

- Лица — в верхней трети (выше 0.45 H), кроме намеренных крупных планов.
- Нижние 260 px — «мёртвая зона»: там живут субтитры и кнопки платформы.
- Поля по 76 px слева/справа: текст и руки не должны их пересекать.

## Линия и форма

| Элемент | Правило |
|---------|---------|
| Основной контур | 5 px при 1080 ширины, цвет `#3B2A26` |
| Внутренние линии | 3 px, тот же цвет, прозрачность 100 % |
| Скругления | минимум 0.25 от высоты элемента — «мультяшная» мягкость |
| Силуэт | читается в чёрно-белом варианте; если нет — форма перегружена |

## Цвет

- Палитра — из `03-CHARACTER-BIBLE.md`, пятнадцать цветов, не больше.
- Один акцент на кадр: либо коралл `#FF6054`, либо горчица `#F0BB4C`.
- Фон всегда на 15–25 % десатурированнее героев — так персонаж «выходит» вперёд.
- Свет: один источник, один тип тени. Никаких «двойных» теней.

## Фоны

- Оверскан **15 %** по каждой оси (чтобы камера двигалась без пустых краёв).
- Три плана: дальний (стена/окно), средний (мебель), передний (предмет на
  переднем плане для глубины, размытый на 3–6 px).
- Детализация снизу выше, чем сверху: ноги/пол/реквизит в кадре часто
  перекрываются персонажем.

## Текст на экране

| Роль | Шрифт | Размер | Регистр |
|------|-------|--------|---------|
| Комедийные выкрики | Montserrat 900 | 170–250 px | КАПС |
| Субтитры | Nunito 700 | 46 px | обычный |
| Плашки времени («ЧЕРЕЗ 3 ЧАСА») | Nunito 800 | 40 px | КАПС |
| Название серии | Montserrat 800 | 64 px | обычный |

- Выкрики: обводка 10 % от кегля, тень со смещением 0.06/0.11 кегля.
- Субтитры: белый текст, мягкая плашка 55 % чёрного, две строки максимум.
- Никогда не набирать текст поверх лица.

## Камера

| Приём | Когда | Параметры |
|-------|-------|-----------|
| Наезд | усиление эмоции | зум 1.05 → 1.16 за 2–3 с |
| Отъезд | ревел (показать масштаб) | 1.35 → 1.02 за 1 с, ease-out |
| Тряска | удар, взрыв, провал | амплитуда 10–26 px, 0.3–0.8 с |
| Панорама | переход между зонами | 4–8 % сдвига, ease-in-out |
| Стоп-кадр | панчлайн | заморозка 0.6–1.0 с + лёгкий зум 1.0 → 1.03 |

Монтаж: не чаще **одного плана на 1.5 с** и не реже **одного плана на 3 с** —
иначе шортс либо дёргается, либо провисает.

## Свет и настроение

| Сцена | Свет | Цветокор |
|-------|------|----------|
| Утро | тёплый, контровой из окна | +5 % яркости, тёплый тон |
| День | ровный, мягкий | нейтральный |
| Вечер | тёплые лампы, глубокие тени | горчичный тон в светах |
| Ночь | холодный, синеватый | −15 % яркости, синий в тенях |
| Драма (шок) | жёсткий контровой | +10 % контраста, коралловый отсвет |

## Зум-стиль для соцсетей

- Первый кадр — статичный «постер» 0.4 с (платформа берёт его как обложку).
- Микро-движение камеры **всегда** (0.5–1 % зума за шот): иначе в ленте кадр
  выглядит как стоп-кадр.
- Переходы: 70 % — прямая склейка, 20 % — whoosh + 6 кадров светового клина,
  10 % — «хлопок в ладоши» на чёрном.

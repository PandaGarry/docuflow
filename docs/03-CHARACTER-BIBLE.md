# 03 · Арт-библия героев

Дизайн собран по референсам реальной семьи (`studio/reference/`). Задача —
узнаваемость в карикатуре: сохранены **силуэт, причёска, борода, одежда и
цветовая гамма**, пропорции утрированы в мультяшную сторону.

> Имена в сериале — рабочие. Как только скажете настоящие (или выберем
> «сериальные»), поменяю в библии и в промптах: имя нужно только для карточек,
> на анимацию не влияет.

## Общая стилистика (стиль B — объём)

- Рост взрослых — 6.5 голов, ребёнок — 5.5 голов (крупная голова, маленькое тело).
- Контура: **нет жёсткой обводки** — форма читается светотенью (см. `13-STYLE-B.md`).
- Свет: key сверху-слева + контровой rim 20–30 %; тени мягкие, переход плавный.
- Кожа: тёплый подтон, лёгкий subsurface на щеках и ушах.

| Одежда | светло-серое худи/свитшот (постоянный элемент), тёмные джинсы |
| Позы-визитки | «уверенный» (руки на поясе, грудь вперёд), «ой» (ладонь у лица), «я всё контролирую» (палец вверх) |

| Комический приём | физическая неуклюжесть при полной уверенности в себе |

## Правила консистентности (жёсткие)

1. **Постоянные элементы нельзя менять между шотами:** борода и виски папы,
   цепочка и жилет мамы, кепка `P` и худи `ABC` сына.
2. **Один герой — один turnaround-лист.** Все позы генерируются с ним в
   референсах, без исключений.
3. **Никаких аксессуаров «от модели»:** лишние сумки, часы, очки, украшения
   удаляются на этапе QA (они «съезжают» между кадрами и ломают узнаваемость).
4. **Руки и ноги:** на каждом кадре ровно две руки и две ноги на героя,
   по пять пальцев на открытой ладони. Это проверяется автоматически.
5. **Никакого текста на одежде, кроме `ABC` у сына** — остальной текст
   добавляем сами поверх кадра, чтобы не ловить «мусорные» буквы от генерации.

## Что нужно сгенерировать для сезона (чек-лист ассетов)

Для каждого героя:

- [ ] turnaround: фронт, 3/4, профиль, спина
- [ ] 8 поз: idle, walk (2 фазы), talk, point, surprise, smug, think, carry
- [ ] 6 форм рта (виземы: A, E, I, O, U, M) + 2 промежуточных
- [ ] 3 состояния глаз: open, half, closed
- [ ] 2–3 брови: neutral, raised, furrowed

Для сцены:

- [ ] фоны: гостиная (день/вечер), кухня, прихожая, двор
- [ ] реквизит: коробки, скотч, шкаф, лампа, пылесос, ноутбук, кружки

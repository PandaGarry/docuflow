# 33 · Арт-дирекшн промо

_Как выглядит промо-кадр: слои, форматы, безопасные зоны, типографика, палитра,
композиция, приёмка. Технические форматы зашиты в
`studio/promo/canon/formats.json`, сборка — `promo.py compose`._

## Три слоя, три источника

```
1. фон            ← генерация (пустая комната, свет, реквизит без надписей)
2. герои          ← ВЫРЕЗКА ИЗ МАСТЕРА (не генерация, не перерисовка)
3. текст          ← наши шрифты, наш слой (модель кириллицу не рисует)
```

Каждый слой отвечает за своё, и это не стилистическое предпочтение, а условие:

- **Генерация не умеет удерживать лицо.** Первая партия промо была нарисована
  моделью по описанию — получились «похожие, но другие» герои. Такой кадр в
  сериал не идёт: зритель узнаёт героя по лицу.
- **Кириллицу модель не пишет.** Попытка получить «ПЕРЕЕЗД» от генератора
  кончается кривой буквой или латиницей, поэтому текст всегда нашим слоем.
- **Реквизит без надписей.** Наклейки, почерк и «мусорные» буквы на коробках —
  тот же брак, что и текст на фоне.

Порядок работы: плата из мастеров (`promo_scene.py`) → типографика
(`promo.py compose`) → проверка (`promo.py verify`).

## Слои и что в них живёт

| Слой | Кто делает | Правила |
|------|------------|---------|
| Фон | генерация | без текста, без логотипов, без «стоковых» иконок |
| Герои | генерация + замок идентичности | [`34-IDENTITY-LOCK.md`](34-IDENTITY-LOCK.md) |
| Реквизит | генерация или наш композит | один предмет-конфликт на кадр |
| Scrim | `compose` | градиент 40 % высоты, у края с текстом |
| Типографика | `compose` | Montserrat 900 / 800, Nunito 700 |
| Брендлайн | `compose` | «ПЕРЕЕЗД · С1», нижний левый угол |
| Эффекты | руками, осторожно | только тёплый свет; никакого неона |

## Форматы и безопасные зоны

| Ключ | Площадка | Размер | Safe | Что перекрывает интерфейс |
|------|----------|--------|------|---------------------------|
| `yt-thumb` | превью YouTube | 1280×720 | 56 px | правый нижний угол — плашка длительности |
| `shorts-cover` | шортс, сторис | 1080×1920 | 72 px | верх 220 px, низ 320 px, края 120 px |
| `post-4x5` | лента TG/VK/IG | 1080×1350 | 64 px | в превью обрезается низ |
| `square` | карусель, кросспост | 1080×1080 | 64 px | аватар обрезается в круг |
| `vk-cover` | обложка VK | 1590×400 | 40 px | слева 280 px (аватар), справа 280 px |
| `avatar` | аватар канала | 800×800 | 90 px | круг r=400 |

Правило, которое спасает чаще всего: **лицо и заголовок никогда не попадают в
`ui`-прямоугольник.** Проверка автоматическая (`promo.py verify`), но глазами
тоже обязательно: скрипт не знает, что у вас лицо закрыто рукой.

## Читаемость: числа, а не вкус

| Параметр | Значение |
|----------|----------|
| Заголовок | до 4–6 слов, до 3 строк (`title_max_words` в формате) |
| Кегль заголовка | ≥ 1/12 высоты кадра, обычно 80–132 px на 1350 px |
| Контраст текста | ≥ 4.5:1; при сомнении — scrim, а не обводка |
| Лицо главного героя | 30–50 % площади кадра (превью), ≥ 12 % высоты (группа) |
| Тест «на 120 px» | уменьшить до ширины 120 px: понятно, что происходит? |
| Тест «на 2 метра» | отойти от монитора: заголовок читается? |

Если после теста «на 120 px» непонятно — кадр не годится, как бы красиво он ни
выглядел в полном размере.

## Типографика

| Роль | Шрифт | Использование |
|------|-------|----------------|
| Заголовок | Montserrat 900 | 1–3 строки, верхний регистр допустим |
| Кикер | Montserrat 800 + трекинг 3 px | «СЕЗОН 1», «СЕРИЯ 2», плашка цвета `#FF6054` |
| Подпись | Nunito 700 | «12 серий по 40 секунд» — не больше 2 строк |
| Брендлайн | Montserrat 700, 70 % непрозрачности | «ПЕРЕЕЗД · С1» |

Правила: кавычки — «ёлочки», тире — длинное, точка в конце заголовка — только
если заголовок из двух предложений. Никаких теней-«мягких подушек» без причины:
тень — 3–5 px, чёрная, 40 % — она держит контраст на светлом фоне.

## Палитра промо

| Роль | Цвет | HEX |
|------|------|-----|
| Бумага / фон карточек | тёплый кремовый | `#FFF8EC` |
| Чернила / текст на светлом | тёмно-коричневый | `#3B2A26` |
| Акцент (кикер, кнопки) | коралл | `#FF6054` |
| Второй акцент (подчёркивание) | горчица | `#F0BB4C` |
| Подложка под текст | почти чёрный | `#1A1210` |
| Шалфей (панели, фон) | `#8AA88A` |
| Текст на тёмном | кремовый | `#FFF8EC` |

Ограничение: **не больше трёх цветов** в кадре, кроме цветов самих героев.
Герои всегда в своей палитре — её нельзя «подкрашивать под фон».

## Четыре композиционные схемы

### 1. Трио в линию (анонсы, обложки)
```
┌──────────────────────────┐
│                          │
│   [папа] [мама] [сын]    │  ← головы на одной линии,
│                          │    порядок всегда один
│  СЕЗОН 1                 │
│  ПАПА ВСЁ ПРОДУМАЛ.      │  ← заголовок в нижней трети
└──────────────────────────┘
```
Работает: когда нужна «семья целиком». Не работает: когда лица мельче 12 %
высоты кадра — тогда лучше схема 2.

### 2. Один герой + реакция (мемы, превью серий)
```
┌───────────────┬──────────┐
│               │          │
│   [папа]      │  текст   │
│   крупно      │  3 слова  │
│               │          │
└───────────────┴──────────┘
```
Правило: второе лицо можно, если оно меньше и в пиксельной близости к главному —
иначе два лица спорят за внимание.

### 3. Предмет-конфликт (гэги)
```
┌──────────────────────────┐
│      [лицо сверху]       │
│          🪛  ← винт      │
│   ЛИШНИЙ ВИНТ            │
└──────────────────────────┘
```
Предмет снимается так, чтобы его было видно на 120 px. Мелкий винт в большой
руке — плохой кадр; винт в поднятой руке у лица — хороший.

### 4. Раскадровка «до/после» (диптих)
```
┌────────────┬─────────────┐
│  Я ВСЁ     │  КОГДА      │
│  ПРОДУМАЛ  │  РАСПАКОВАЛ │
│  [папа]    │  [папа]     │
└────────────┴─────────────┘
```
Два кадра одного героя в одном состоянии мира — самая дешёвая «шутка в картинке».

## Что делает превью кликабельным

1. **Одно лицо, одна эмоция, читаемая на 120 px.** Не «спокойное» лицо, а состояние.
2. **Один объект-конфликт.** Коробка, винт, стопка пицц, пустая рамка.
3. **Диссонанс.** Уверенное лицо + разрушенный мир вокруг. Это и есть гэг.
4. **Воздух под текст.** Если его нет, заголовок ляжет на лицо и убьёт кадр.
5. **Тёплый свет.** Сериал про дом, а не про офис: холодный свет = другой жанр.

## Чего не делаем

- Кислотных обводок, «ютубных» стрелок и кругов, нарисованных поверх героев.
- Текста, нарисованного моделью (кривая кириллица, «мусорные» буквы).
- Стоковых иконок, эмодзи внутри картинки, звёздочек, «блеска».
- Меняющихся аксессуаров: очки, часы, сумки, серёжки — ломают узнаваемость.
- Резкого зума на лицо в групповом кадре: рука/плечо соседа превращается в пятно.
- Виньеток, blur по лицу, плёночного зерна — это другая стилистика.
- Разных фонов «одной и той же комнаты» в одной серии постов: мебель поедет.

## Приёмка креатива (12 пунктов)

- [ ] Размер и пропорции точно совпадают с форматом (`promo.py verify` — PASS).
- [ ] Заголовок и лица вне безопасных зон и вне `ui`-областей.
- [ ] У героя узнаваемое лицо: борода/виски, чёлка/цепочка, кепка `P` + `ABC`.
- [ ] Пропорции не «похудели» и не «вытянулись» (сверить с линейкой семьи).
- [ ] Ровно две руки, две ноги, пять пальцев на открытой ладони.
- [ ] Нет постороннего текста, логотипов, водяных знаков от модели.
- [ ] Один объект-конфликт читается на 120 px.
- [ ] Заголовок ≤ 3 строк, читается за 1 секунду.
- [ ] Контраст текста ≥ 4.5:1, scrim не съел лица.
- [ ] Палитра героев не изменена под фон.
- [ ] Вес файла ≤ 8 МБ, формат PNG/JPG по требованиям площадки.
- [ ] В имени файла есть ID поста (`P10-shorts-cover.png`).

Не прошло хоть один пункт — кадр не публикуется. Исключений «пойдёт и так» нет:
превью — это единственное, что зритель видит до того, как решит смотреть.

## Что показал первый прогон (и почему подход переделан)

Первая партия была сделана генерацией по текстовому описанию героев. Она
забракована целиком: лица и пропорции не совпадали с мастерами. Причина
брака — в самом методе, а не в формулировке промпта:

| Что случилось | Причина | Вывод |
|---------------|---------|-------|
| Лица не совпадали с мастерами | модель рисует нового персонажа по описанию | героя не генерируем вообще |
| Подача референсов лица не помогла | модель усредняет черты | текстовые и референсные промпты — для фона, не для героев |
| Обувь, складки, принты «уезжали» | детали задаются заново каждым кадром | берём пиксели мастера |
| Буквы алфавита на вороте худи | модель «дописывает» текст | реквизит и одежда — только с мастера |

Что работает вместо этого:

1. **Плата из мастеров** (`promo_scene.py`): герой — вырезка, масштаб по канону
   голов, общая линия подошв, контактная тень.
2. **Пустой фон** генерируется отдельно (`studio/promo/plates/`), с блоком
   «no people» в промпте.
3. **Типографика** слоем: `--plate` (полупрозрачная плашка) для карточек и
   вертикалей, `scrim` для анонсов на светлом фоне.
4. **Доказательство** `promo_scene.py proof`: совпадение силуэта с мастером
   99,41–99,85 % — лицо не перерисовано.

## Плакаты прогрева

Отдельный движок `studio/engine/promo_poster.py` делает плакаты без фона: плоский
цвет, крупный шрифт, герой из мастера. Шесть режимов — `announce`, `quote`,
`silhouette`, `portrait` (круг с лицом), `faces` (три лица), `meme`.

Силуэт — это альфа мастера, залитая чернилами: герой читается по контуру, но
лица не показывает. Кроп лица для кругов берётся из мастера, высота головы — из
канона, поэтому в круге оказывается ровно голова, а не «примерно верх картинки».

Зачем это нужно: пока серии не готовы, сообщество заполняется героями и тоном, а
не анонсами. Пока название и стиль не выбраны, плакаты не собираем: сначала
`docs/40-CHARACTERS.md`.

## Как собрать креатив

```bash
# 1. фон: пустая плата (без людей!) — единственное место для генерации
.venv/bin/python studio/engine/promo.py prompt --format post-4x5 \
    --scene "living room with cardboard boxes, daylight" --cast dad,mom,son

# 2. плата: фон + герои из мастеров (никакой генерации персонажей)
.venv/bin/python studio/engine/promo_scene.py scene --format post-4x5 \
    --cast dad:hips,mom:stern,son:point \
    --bg <плата.png> \
    --dad 0.50 --baseline 0.64 --out studio/promo/renders/P01-art.png
# 3. типографика поверх арта
.venv/bin/python studio/engine/promo.py compose studio/promo/renders/P01-art.png \
    --format post-4x5 --kicker "СЕЗОН 1" --title "Папа всё продумал" \
    --sub "12 серий по 40 секунд" [--plate] --out studio/promo/renders/P01-post-4x5.png

# 4. проверка
.venv/bin/python studio/engine/promo.py verify studio/promo/renders/P01-post-4x5.png
```

Именование файлов: `P01-art.png` — арт без типографики (промежуточный),
`P01-post-4x5.png` — финальный креатив под формат. `verify` проверяет только
финалы, промежуточный арт пропускает.

# 08 · Пошаговый план

Порядок важен: каждый этап снимает риск следующего. Не начинаем арт, пока не
выбран стиль; не начинаем сезон, пока пилот не прошёл приёмку.

## Этап 0 · Фундамент ✅ сделано

- [x] Репозиторий очищен от предыдущих роликов
- [x] Каркас студии (`studio/`), шрифты с кириллицей (Montserrat + Nunito)
- [x] Документация: 12 файлов (`docs/00`–`11`)
- [x] Сезонная арка на 12 серий
- [x] Каркас движка рига + демо-рендер

**Выход:** репозиторий-студия, в котором понятно, что делать дальше.

## Этап 1 · Выбор стиля ⏳ ждём вас

- [x] 4 варианта × 2 кадра: `studio/style-tests/`
- [ ] **Вы выбираете вариант (A / B / C / D)**
- [ ] Я фиксирую стайлгайд: толщина линии, палитра, пропорции
- [ ] Тест «3/4 поворот»: проверить, что стиль держится не только во фронт

**Почему важно:** смена стиля после арт-библии означает переделку всех ассетов.

## Этап 2 · Арт-библия героев (2–3 сессии)

- [ ] Turnaround-листы: папа, мама, сын (фронт, 3/4, профиль, спина)
- [ ] 8 поз на героя + 6 форм рта + 3 состояния глаз
- [ ] QA-прогон каждого листа (`engine/qa.py`), ручной лист
- [ ] Фоны: гостиная (день/вечер), кухня, прихожая, двор
- [ ] Реквизит серии 1: коробки, скотч, нож

**Приёмка:** шлюзы 1–3 из `06-QA-CHECKLIST.md` зелёные.

## Этап 3 · Движок: доводка рига (1–2 сессии)

- [ ] Разбиение turnaround на слои по суставам (конфиг `characters/*.rig.json`)
- [ ] Базовые циклы: idle, walk, talk, react — сохранить как пресеты
- [ ] Вторичная анимация: spring для волос/бороды/капюшона
- [ ] Липсинк: фонемы → виземы → кадры (русские правила)
- [ ] Демо-ролик «живой» анимации 10 с для приёмки

**Приёмка:** движение читается как мультфильм, а не как перестановка картинок.

## Этап 4 · Пилот: серия 1 «Коробки» (2–3 сессии)

- [ ] Сценарий JSON (`studio/episodes/ep01.json`) + валидация
- [ ] Раскадровка 7 шотов (текстовые описания + превью-кадры)
- [ ] Озвучка (2 голоса), музыка, эффекты
- [ ] Рендер, субтитры, постер
- [ ] Полная приёмка по чек-листу
- [ ] **Ретроспектива:** что заняло больше времени, что автоматизировать

**Приёмка:** серия готова к публикации, время производства ≤ 1 день.

## Этап 5 · Конвейер серий 2–3

- [ ] Новые ассеты: винт, шкаф, диван, пульт
- [ ] Переиспользование: 70 % ассетов из пилота
- [ ] Автоматизация: один скрипт собирает серию из JSON
- [ ] Замер: время на серию должно упасть до ~5 часов

**Приёмка:** две серии подряд без «съехавших» героев.

## Этап 6 · Сезон до конца (серии 4–12)

- [ ] По 2–3 серии за итерацию
- [ ] Ревизия арки: не «провис» ли темп (карточки в `07`)
- [ ] Единый визуальный аудит сезона: палитра, линия, шрифты
- [ ] Финальная сборка: плейлист, обложки, порядок публикации

**Приёмка:** 12 серий, суммарно ~8 минут экранного времени.

## Что мне нужно от вас на старте

| Что | Зачем | Когда |
|-----|-------|-------|
| Выбор стиля A/B/C/D | всё остальное зависит от него | сейчас |
| Имена героев (можно вымышленные) | карточки серий, промпты, титры | до этапа 2 |

## Риски и как снимаем

| Риск | Вероятность | План |
|------|-------------|------|
| Герой «съезжает» между шотами | высокая | один шаблон + turnaround в референсах + QA-шлюз |
| Анимация выглядит «деревянной» | средняя | циклы и spring-вторичка, приёмка по демо-ролику |
| Серия не смешная | средняя | карточка серии с панчлайном до арта; читаем вслух |
| Много времени на арт | средняя | ассеты библиотекой, реквизит переиспользуется |
| Ошибки анатомии | высокая | автопоиск конечностей + ручной лист каждого шота |

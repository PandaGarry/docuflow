# 2.5D: кукла из сгенерированного мастера

Итог: путь «сгенерировать картинку → оживить нарезкой» собран и работает.
Движок — `studio/engine/cutout.py`, проверка — `studio/tools/pose_sheet.py`.

```
python studio/tools/pose_sheet.py     # studio/out/dad-poses.png + dad-wave.mp4
```

## Как устроено

1. **Хромакей** (`key_green`) — мягкая альфа по «зелёности» + despill, чтобы по
   контуру не оставался зелёный ободок. `trim` убирает поля.
2. **Скелет** (`Rig`, `DAD_BONES`) — 17 костей в долях роста, прямая кинематика:
   `world_rot = rot_родителя · R(угол)`, `world_head = поза_родителя + поворот`.
   Поза — словарь «кость → угол в радианах» + сдвиг корня.
3. **Детали** (`CutoutPuppet`) — силуэт режется по анатомическим линиям на
   восемь жёстких частей: торс, голова, две руки целиком (рукав + кисть),
   два бедра, две голени со стопами.
4. **Сборка кадра** — каждая деталь переносится жёстко (поворот вокруг своего
   сустава + перенос родителя) и «сплэтится» в один буфер в порядке отрисовки.
   Буфер рисуется с запасом 2× и уменьшается — кромка гладкая. Проколы от
   округления закрываются заливкой от соседей.

Линии разреза (доли роста, замерены по `master-front.png`):

| граница | значение |
|---|---|
| шея / голова | v = 0.215 |
| рука снаружи, выше подмышки | u > 0.115 |
| рука снаружи, ниже подмышки | u > 0.098 |
| рука: низ (кончики пальцев) | v = 0.84 |
| пах / бёдра | v = 0.652 |
| колено | v = 0.82 |
| ширина таза | 0.105 H |

## Что пробовали и почему отказались

- **Скиннинг сетки (как в 3D)**: веса по ближайшим костям, меш-варп PIL.
  Смешанные веса «жуют» рукав — поднятая рука растягивает полотно; при
  жёстком назначении ломаются стыки. Кромка рвётся, появляются «языки».
- **Наложение спрайтов с заглушками**: даёт двойные контуры и «призраков»
  (мягкая подкладка дублировала руку в покое).
- **Перекрытие деталей по всей границе**: корпус «отращивал» полосу рукава, и
  при подъёме руки эта бахрома висела в воздухе. Перекрытие нужно только в
  районе сустава.
- **`np.roll` для сдвигов**: заворачивает кадр по краям и оставляет полосы.
- **Разрез по ближайшей кости**: внутренняя кромка рукава уходит к корпусу,
  за рукой остаётся полоса-призрак. Режем геометрическими линиями.
- **Детали мельче**: кисть и предплечье отдельно, сгиб локтя. На плоской
  картинке тонкий сгиб всегда рвётся. Рука — одна деталь.

## Честные ограничения

- Локоть не сгибается; кисть не вращается отдельно от рукава.
- Нет ракурсов снизу/сверху/«через плечо»; нет честного 360°. Виды берутся из
  мастер-листа (фронт / три четверти / профиль / спина).
- Внутренние поверхности (подмышка, изнанка рукава) не нарисованы — на сгибах
  подставляется ближайшая ткань, а не полноценная геометрия.
- Это кукольная анимация, а не 3D-рендер: пластика «на 8 деталях».

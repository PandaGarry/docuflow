# Лицо: глаза, рот, мимика

Как устроена «живость» лица. Модуль — `studio/engine/facefx.py`.

## Принцип: база + слои, а не генерация каждого кадра

Каждый новый кадр от генератора немного другое лицо, поэтому мимику нельзя
«перегенерировать на каждый звук» — лицо поплывёт. Схема как в 2D-сериалах:

| что | откуда берётся |
|---|---|
| база кадра | `emotions/<эмоция>.png` (готовый портрет) |
| моргание | `emotions/eyes-closed.png` + опускание века |
| взгляд | сдвиг зрачка внутри глаза |
| речь | `visemes/<форма>.png`, из них берутся только губы |
| дыхание | микросдвиг всей головы по синусу |

## Разметка лица (обязательна)

Автопоиск зрачков по тёмным пятнам **не работает** на этих портретах: в тёмные
пятна попадают брови и борода, «межзрачковое расстояние» гуляло от 16 до 400 px.
Поэтому лицо размечается один раз по сетке 10×10 и лежит в
`studio/2p5d/<персонаж>/face.json`:

```
глаза: L (0.368, 0.264), R (0.625, 0.264), ipd 0.257, eye_w 0.091, eye_h 0.040
рот:   центр (0.499, 0.366), ширина 0.180, высота 0.055
брови, нос, подбородок — тоже там
```

Разметка — часть канона: меняется только при смене персонажа или ракурса.
Проверка глазами: наложить прямоугольники на кадр
(`facefx.landmarks_px` → нарисовать) и посмотреть, что глаза накрыты точно.

## Моргание

`facefx.blink(base, closed, lm, amount)`:
- `amount=0` — открыто, `1` — закрыто;
- не смешивать кадры: полупрозрачное наложение двух разных век даёт смаз;
- веко «напускается» сверху вниз вертикальной маской с мягкой границей;
- маска ограничена овалом глаза, поэтому брови и борода не меняются.

Результат проверен: 0 / 0.35 / 0.7 / 1.0 читаются как естественное смыкание.

## Речь (виземы)

Формы для русского: `rest, A, E, I, O, U, M, F, S`.
`facefx.morph_mouth(base, viseme_img, lm)`:
- берём из визема **только изменившиеся пиксели** (разность кадров выше
  порога), а не овал целиком;
- иначе вокруг рта видно кольцо: генератор рисует слегка другое лицо;
- маска дополнительно ограничена овалом вокруг рта по разметке, край сглажен.

Проверено: 5 кадров (база + М, Э, А, О) — рот меняется, лицо остаётся тем же.

## Ограничения, которые надо помнить

1. **Только фронт.** При повороте головы больше ~15–20° разметка лица не
   совпадает с картинкой, и моргание с ртом поедут. Для профиля нужны свои
   базы и своя разметка.
2. **Голова должна быть в одном масштабе.** В портретах эмоций `head_w`
   отличается (537…710), поэтому вклеивать мимику в полный рост надо с
   масштабированием по `ipd`, а не по ширине головы.
3. **Рот и моргание независимы** — можно моргать во время речи, слои не
   конфликтуют (разные области).

## Что дальше по лицу

1. Добить виземы `I, U, F, S, rest` (в работе).
2. Собрать тестовый клип: «нейтрально → моргание → фраза из 4 виземов»,
   посмотреть стыки на 12–15 fps.
3. Проверить, как это работает поверх тела (поза + вклеенная голова):
   понадобится маска шеи и подгонка по `ipd`.

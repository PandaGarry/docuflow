# Мультик «Уборка» — карикатурный шортс, 9:16, 33 с

Весёлая короткая история в стиле современных анимационных шортсов: ребёнок
выпросил гостей, после гостей — бардак, мама просит убрать игрушки… а дальше
панчлайн, ради которого всё и снято.

> Ролик собран полностью программно: персонажи и фоны нарисованы ИИ в едином
> плоском стиле, анимация — покадровая cut-out анимация на Python (PIL/numpy),
> звук синтезирован и озвучен, монтаж — через ffmpeg. Ни одного монтажного
> приложения.

## Готовые файлы

- `out/toys-cleanup.mp4` — 1080×1920, 30 fps, ~33 с, H.264 + AAC, −14 LUFS
- `out/toys-cleanup.srt` — субтитры по репликам
- `out/poster.jpg` — кадр-обложка

Драматургия намеренно короткая: 4 секунды на завязку, 8 на вечеринку и бардак,
и почти половина ролика — на паузу перед панчлайном. Комедия держится на
контрасте: чем дольше ребёнок молчит и ухмыляется, тем смешнее реплика.

## Как это анимировано

Персонажи — отдельные спрайты в 4–5 позах (просящий, ликующий, ухмыляющийся,
указывающий, испуганный; мама — мягкая, строгая, в шоке, плюс отдельный
портрет для крупного плана). Дальше — классический cut-out:

- «дыхание» и покачивание: синусоидальные смещения и поворот ±1–2°;
- сквош-стретч: масштаб по осям, сжатие на ударных кадрах;
- появление «пружинкой» (ease-out-back), подскок с overshoot;
- камера: зум/панорама по фонам с запасом (оверскан), тряска на склейках;
- фон доводится цветокором по сцене (тепло для уюта, приглушение после хлопка);
- графика: речевые пузыри с хвостом, комикс-надписи с обводкой и тенью,
  лучи-«бум», спидлайны, конфетти с физикой падения, пыль, вспышки.

## Звук

- Музыка: укулеле-перебор (пиццикато с обертонами) + бас + шейкер + клэпы,
  C–G–Am–F, 112 BPM; громкость следует за сценой (`timeline.MUSIC`), на паузах
  уходит в тишину.
- Эффекты: pop, конфетти-звон, скретч пластинки, хлопок двери, сверчки, стинг,
  boing, whoosh, искры — всё синтезировано и расставлено по `timeline.SFX`.
- Голоса: две озвучки (мама и ребёнок). Детский голос поднят по тону и ускорен,
  мамин — чуть ниже и теплее; реверб, компрессия, дакинг музыки под реплики.
- Мастеринг: −14 LUFS, пик −1.5 dBTP (норма соцсетей).

## Пересборка

```bash
python3 -m venv .venv && .venv/bin/pip install pillow numpy imageio-ffmpeg fonttools brotli
./build.sh                      # всё: спрайты -> звук -> видео -> субтитры
./build.sh --preview 8.5 24     # только кадры для проверки вёрстки
```

Правки истории — в `scripts/timeline.py`: реплики, окна сцен, комикс-надписи,
точки эффектов, окна музыки. Озвучка — файлы `audio/vo_*.mp3`; замените своими
записями с теми же именами (длительности пересчитываются автоматически).

## Структура

```
scripts/timeline.py   тайминг, реплики, надписи, эффекты, музыкальные окна
scripts/cutout.py     вырезание спрайтов по зелёному фону (chroma key + despill)
scripts/art.py        примитивы: комикс-текст, пузыри, персонажи, эффекты
scripts/render.py     сцены и сборка кадра, рендер в ffmpeg
scripts/make_audio.py музыка, саунд-дизайн, микс с озвучкой
scripts/make_subs.py  субтитры .srt
build.sh              полная пересборка
assets/raw/           исходные генерации на зелёном фоне
assets/chars/         вырезанные спрайты (RGBA)
assets/bg/            фоны комнаты: чистая и после «уборки»
audio/                vo_*.mp3, music.wav, mix.wav
out/                  mp4, srt, poster
```

## Лицензии

- Шрифт Montserrat — SIL OFL 1.1 (`shared/fonts/OFL.txt`).
- Музыка и эффекты синтезированы скриптом — ограничений нет.
- Персонажи и фоны сгенерированы ИИ для этого ролика; совпадения случайны.

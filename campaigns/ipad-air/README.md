# Концепт-ролик «iPad Air» — 9:16, 42 с

Рекламный концепт-ролик, полностью собранный программно: кадры → цветокор →
движение камеры → кинетические титры → монтаж с переходами → музыка, саунд-дизайн
и озвучка → мастеринг в MP4.

> ⚠️ Это **неофициальный концепт**. Apple, iPad Air, M3, Apple Pencil — товарные
> знаки Apple Inc. Видео не является рекламой и не аффилировано с Apple.
> Все продуктовые кадры — AI-сгенерированные иллюстрации, а не реальное устройство.

## Готовый файл

`out/ipad-air-promo.mp4` — 1080×1920, 30 fps, H.264 High, AAC 192 кбит/с,
громкость −14 LUFS (норма для соцсетей), ~42 с.

## Структура

```
scripts/timeline.py    тайминг сцен, тексты, точки склейки, тайминг голоса
scripts/make_music.py  синтез музыки и саунд-дизайна (numpy) + микс с озвучкой
scripts/render.py      рендер кадров (PIL/numpy) -> ffmpeg, превью-режим
build.sh               полная пересборка: голос -> звук -> видео
assets/scenes/         AI-кадры сцен (768×1376)
assets/fonts/          Montserrat 300–900, латиница + кириллица в одном файле
audio/                 vo_*.mp3 (озвучка), music.wav, mix.wav
out/                   ipad-air-promo.mp4, постер
```

## Пересборка

Нужны Python 3.10+, ffmpeg (берётся из `imageio-ffmpeg`):

```bash
python3 -m venv .venv
.venv/bin/pip install pillow numpy imageio-ffmpeg fonttools brotli
./build.sh                     # полный цикл
./build.sh --preview 9 18.5 36 # только статичные кадры для проверки вёрстки
```

`build.sh` вызывает `make_music.py` (аудио) и `render.py` (видео) и кладёт
результат в `out/`. Озвучка — файлы `audio/vo_*.mp3`; замените их своими
записями с теми же именами, и тайминг подхватится автоматически (длительности
читаются из файлов, точки входа — в `timeline.VO`).

## Как сделано

- **Кадры.** Текстовые генерации в стиле продуктовой фотографии + апскейл до
  рабочего разрешения с запасом под зум.
- **Цветокор.** Четыре пресета (cool / warm / neutral / vivid): контраст,
  насыщенность, тон в светах, цвет в тенях; локальный unsharp.
- **Камера.** Ken Burns на каждый кадр: зум 1.02→1.26 и панорама по Y с
  ease-in-out, так что движение не «дёргается».
- **Титры.** Montserrat, трекинг, кинетическое появление (сдвиг + fade),
  аддитивное свечение, акцентная линия у надзаголовков, автоподгонка размера под
  поля кадра, мягкая затемняющая панель для контраста на любом фоне.
- **Переходы.** Кроссфейд 0.55 с + световая вспышка, горизонтальный световой
  клин и хроматическая аберрация на склейке.
- **Финал.** Хром-градиент в логотипе, свечение, блик-свип, дисклеймер.
- **Звук.** Аккордовая сетка Am–F–C–G: пэды, арпеджио, кик, тики, райзер;
  импакты точно на склейках, whoosh на переходах; свёрточный реверб, дакинг
  музыки под голос, мастер-сатурация, нормализация −14 LUFS.
- **Грейд и текстура.** В ffmpeg: виньетка, лёгкое зерно, `+faststart` для
  мгновенного старта в вебе.
